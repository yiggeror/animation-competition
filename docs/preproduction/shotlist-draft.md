# 镜头表草稿

> 原则：用少数几个固定机位讲故事（机位见 `floorplan.png` 的 A–E），不切碎。目标 **约 34 个镜头**（之前一部 5 分钟的片子切了 71 个）。
> 镜头运动只在有目的时用：慢推近床单、来电硬切、结尾退出窗外。
> 时长是估计，动态分镜阶段按音乐和表演调整。

**机位**
- **A 全景**：东南角看向西北。前景右侧是八仙桌一角，中景是竹席、奶奶、电视，背景是北边的晾衣铁丝/床单和木柱。
- **B 床单正面**：小满在左下角（只露头和肩，不挡床单）。
- **C 床单背面**：后台西北角，看奶奶（和小满）的侧脸、手、签子、马灯和床单背面。
- **D 侧面**：从东边沿着床单看，床单前后两边同时入画。
- **E 屋外**：从南窗往后退到村子。
- **特写**：手、脸、手机、皮影、插座、拉线开关等，机位跟随所在场景的主光方向，不跳轴。

## 镜头间的连贯
- 光的方向：停电前主光是日光灯（顶光偏南），停电后先是南窗月光，再是马灯（从东北角立柜移到床单后）。每个特写的受光方向都按此确定，不随镜头乱变。
- 轴线：床单戏（第 6–12 场）的轴线是床单平面。正面镜头在南侧，背面镜头在北侧，侧面镜头 D 正好骑在轴线上，用来过渡。
- 音乐不跟着剪辑换段：切镜头时音乐连续（配乐段落表另做）。
