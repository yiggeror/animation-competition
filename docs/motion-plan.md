# 人物动作计划（骨架驱动版）

> 依据：用户 2026-10-17 的意见——静态图平移、表情不变显得"伪人"。
> 做法：每张人物图绑骨架（`js/rig/warp.js`，格式见 `collab/claude.md` 08:55 / 09:30），动作连续；程序眨眼；大姿态换图藏在快动作中段。
> 分工：**R** = 绑骨数据，**M** = 动作曲线（镜头模块里的骨骼关键帧）。"A" 指 Astra，"O" 指 Opus。

## 通用动作要求（每个出人的镜头都要有）

- **呼吸**：脊柱 sy 1±0.005，周期 3～4 秒。
- **眨眼**：每 2.5～5 秒一次，不规则；转头、换姿态的时候顺带眨一次。
- **视线和头**：看谁就转向谁。转头先动眼（眨眼）、再动头、最后带肩，每段延迟 0.1～0.2 秒。
- **手**：手里有东西时手在干活，空手时有小的重心和手指调整。不能出现整只手一动不动超过 2 秒。
- **接触**：贴地、贴席、握住的东西用 pins / regions 固定，不能滑。
