# 第 3–12 场 人物画稿清单（草案，等用户点头再开画）

做法跟开场一样：人物全部逐帧画（姿势、表情变了就换张，快动作一张停 2～3 帧，慢动作和停顿用同一张多停几帧）；光、影子、皮影、道具、镜头、声音由代码做。
每个镜头开画前先出骨架参考（Astra 在自己的画上标关节，骨长固定），近手、躯干、远手分三层画清；两臂交叠、手腕压在身上、肘叠在一起的参考一律不过。
张数是估计，按 S18（3 秒 12 张，用户认可）的密度算，动作多的地方可以加，不设上限。

## 合计和时间

- 第 3–12 场新画约 310 张；开场还剩约 70 张（S03a 2、S05a 3、S07 约 25、S08 32、S01、S04）。
- 按今天的出图速度（每小时十几张过审），开场今晚到明早画完，第 3–12 场 10-19 到 10-21 画完，10-22 合成、配声、全片检查，10-23 交。
