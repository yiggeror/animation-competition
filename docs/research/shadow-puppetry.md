# 皮影查证笔记

> 目的：让片中的皮影、操纵手法和音乐经得起懂行的人看。每条结论后附来源；网上资料互相矛盾的地方单独标出。

## 1. 结论先行（直接影响制作的决定）

| 问题 | 决定 | 依据 |
|---|---|---|
| 参照哪个流派 | **湖南皮影** | 《龟与鹤》是湖南皮影的代表剧目；故事设定在南方乡下，奶奶年轻时在乡里戏班演过戏 |
| 影人材质 | 硬牛皮（刮薄、透光），颜色饱满、对比强 | 湖南潮湿，影人必须用硬质材料（硬纸板或硬牛皮），线条简洁明快、色彩对比强烈 |
| 操纵方式 | **平端签子**：签子大致垂直于幕布端平，影人贴紧幕布 | 湖南因影人硬，多"平端"；北方软皮影多斜举。平端让影人贴幕、细节清楚，**也避免手影误投到幕布上** |
| 鹤怎么操纵 | 原作需两人（一人"上影"、一人"下影"）；片中奶奶一人独演 | 老艺人能一人同时操纵上影和下影——这正好用来交代奶奶的本事 |
| 乌龟怎么操纵 | 一人操纵，**特点是慢**，初学者最容易做不好 | 学员练乌龟时，老师一遍遍喊"慢！要慢！" |
| 戏的性质 | 湖南皮影艺术家**何德润、谭德贵**于 20 世纪中叶创作的动物寓言皮影戏，**无对白，国乐丝竹伴奏**；1965 年第三届国际木偶节（罗马尼亚）获最佳演出奖 | 见来源 1–4 |
| 剧情 | 鹤自恃嘴尖能飞、骄傲轻敌，与龟相争，最后被龟咬住（各版本细节不一：有争湖心礁石的，也有鹤救青蛙的） | 见来源 1、3、4 |

### 这些查证给剧本带来的东西
1. **第 8 场"慢一点，再慢一点"是真的。** 乌龟本来就是"慢"的戏，初学者最容易急。奶奶把最简单的乌龟交给小满，小满还是演砸了——这既好笑又真实。
2. **第 9 场小满故意把手伸进光里，是在"犯规"。** 湖南艺人平端签子，就是为了不让手影上幕。小满偏把手影放进去——老戏演成新戏，在手艺层面也成立。
3. **原作的鹤要两个人才演得动。** 奶奶一个人演鹤是老艺人的本事；后来祖孙两人一起演，正好回到这出戏"本来需要两个人"的样子。这一点写进制作说明。
4. **原作无对白、丝竹伴奏。** 我们的片子也无对白，用丝竹味的配乐，和原作同一路数。
5. **片中第 8 场的笑点"乌龟反咬鹤嘴"，正是原作的结局。** 我们只把"咬死"改成"咬一口"，保持轻喜剧。

### 版权与表述
- 皮影戏是国家级非遗（2008 年扩展项目"皮影戏（湖南皮影戏）"，编号 Ⅳ-91），2011 年中国皮影戏列入联合国教科文组织人类非物质文化遗产代表作名录。作为传统文化的象征，用在片里没有问题。
- 《龟与鹤》这出戏本身是有作者的新创剧目（20 世纪中叶）。片中只借用"鹤啄龟、龟咬鹤"这一寓言情节作致敬，**鹤和乌龟的造型全部原创**，不照搬湖南省木偶皮影艺术保护传承中心的偶形。制作说明里写作"湖南皮影经典剧目《龟与鹤》"，并注明创作者。
- 资料分歧：有的腾冲（云南）资料把《龟与鹤》列为腾冲皮影剧目，湖南资料列为湖南剧目；两边都写创作者是何德润、谭德贵。片中不涉及归属，制作说明按湖南的说法写，并注明有此分歧。

## 2. 影人的构造（设计鹤和乌龟时照着做）

### 2.1 人物影人（用于奶奶老照片里的戏台、片尾等，鹤龟不需要）
- 一个完整影人通常 **11 个部件**：头、胸、腹、双腿、双上臂、双下臂、双手（各流派略有出入）。
- 头部（含帽、须、颈）单独雕刻，颈下端是一个楔子，演出时**插进胸部上方的卡口**——所以一个身子可以换很多头。
- 关节处刻成**轮盘式的枢纽**（老艺人叫"骨缝"），避免肢体叠合处出现太多重影；连接点叫"骨眼"。
- 用牛皮刻成的**枢钉**或细牛皮条搓成的**线**把部件连起来（"缀结"），是最后一道工序。
- **三根签子**：一根主签装在胸部（文场人物装在胸上前部，用铁丝连接，能让影人反转；武场人物装在胸后上部，方便打斗），双手各装一根手签。

### 2.2 动物影人（鹤、乌龟）
- 鹤：有剧团把仙鹤的颈部做成 **28 节**衔接（远多于人的 7 节颈椎），所以脖子动起来非常柔顺；还设计了"鹤三步"——三步就能穿过整个幕布。我们的鹤：颈部 10–14 节（数量多到看起来柔顺、少到能看清每一节的枢钉），腿分大腿、小腿、脚三段。
- 原作鹤分上影、下影两人操纵（推测上影管身、颈、头，下影管腿；资料没写清具体分工，片中按这个合理推断设计）。
- 乌龟：一人操纵。资料里**没有找到传统皮影乌龟缩头机关的做法**。片中的设计：头和颈是一个部件，枢钉在龟壳前缘内侧，由一根签子牵动；缩头时颈部绕枢钉转进龟壳后面，被龟壳挡住——这是平面皮影能做到的、最朴素的办法，制作说明里注明是我们的推断设计。
- 没装签子的部件（鹤的腿、龟的四肢）靠惯性自然摆动——这是皮影动作"韵味"的来源之一。

### 2.3 工艺与材质（决定透光的样子）
- 工序（说法不一）：选皮 → 制皮（刮薄、泡亮，两面刮净直到透明）→ 画稿 → 过稿 → 镂刻（3000 余刀）→ 敷彩 → 发汗熨平 → 缀结。
- 雕刻以**阳刻**为主（保留线条，挖掉面），也用阴刻（保留面，挖掉线条），或阴阳结合。
- 敷彩：传统颜色多取自矿物和植物，主色红、黄、绿、黑，透光后像彩色玻璃。
- 发汗熨平：约 70℃ 脱水，让颜色渗进皮里、皮面平整。**片中的视觉含义：** 颜色在皮的内部，所以透光是"整片发光"的，不是表面一层颜料；未着色处是牛皮本色——透光时是温暖的琥珀色，不是白色。
- 湖南皮影特点：线条简洁明快、图案突出、色彩对比强烈；刀法丰富，虚实结合、繁简相映。

### 2.4 演出
- 湖南皮影常露天演出，观众听不清唱词，所以**更重动作**：稳健准确、细腻传神。
- 多人操纵一个角色很常见（狗熊奔跑：一人管头和前肢，一人管后肢，按同一频率交替）。
- 用多个光源，避免签子的影子上幕（现代剧团用无影光源）。**片中奶奶家里只有一盏煤油灯，所以签子会在幕上留下淡淡的影子**——这是家庭小戏的样子，也是真实光照计算的结果，不去掩盖。

## 3. 音乐
- 湖南皮影唱腔多用湘剧、花鼓戏腔调；伴奏有鼓、锣、唢呐等。
- **大筒**：形似二胡、琴筒较大，是湖南花鼓戏的主要伴奏乐器。
- 《龟与鹤》原作全剧无对白，用国乐丝竹伴奏。
- 片中配乐的乐器方向：笛子（主旋律）+ 大筒/二胡音色 + 梆子、小锣、木鱼（节奏，对应皮影"跟着锣鼓点走"）+ 弹拨（扬琴/琵琶）。"现代的声音"见配乐设计文档（计划：用小满手机游戏里的芯片音乐音色，在第 9 场和丝竹一起玩）。
