# 《来电》制作说明（答辩用，草稿）

> 状态：成片制作中（2026-10-17）。镜头完成情况见 `PROGRESS.md`，AI 参与的逐日记录见 `docs/ai-usage-log.md`。

## 一、作品

**故事。** 夏夜，乡下的堂屋。9 岁的小满趴在竹席上打手机游戏，电量 2%，插着充电。忽然停电：日光灯灭了，电视缩成一个亮点，手机掉到 1%、黑屏。她插了又拔、拔了又插，最后瘫在竹席上。

奶奶不慌不忙点起一盏马灯，从樟木箱里拿出年轻时在戏班里用过的皮影。她把床单搭在晾衣铁丝上，把马灯挂在床单后面，演起了《龟与鹤》。小满先是装作不感兴趣，后来看呆了，再后来上手，把乌龟演砸了，又在奶奶手把手的带领下演成了。两个人越演越起劲，小满还用手电打出一只手影小狗来追鹤。

就在最热闹的时候，来电了。日光灯从正面一照，床单上的影子几乎全消失了。手机亮了，开始充电。小满看看手机，又看看奶奶，走到门边拉灭了电灯。马灯的光重新显出来，戏接着演。

最后镜头退到屋外：家家户户亮着白灯，只有这扇窗是暖黄的，窗里有鹤和乌龟的影子。

- 时长：约 4 分 05 秒（31 个镜头）。
- 无对白。
- 片名"来电"一语双关：电来了，人和人之间也"来电"了。

**主题。** 不是"手机不好、传统好"的说教，而是一盏灯照亮的世界，比一屋子白光照亮的世界小，但那里有人和人在一起。全片的光都有来处，故事是用光讲的：
- 停电，屋里只剩月光和手机屏的冷光。
- 马灯一亮，暖光把蓝色挤到窗边。
- 皮影戏全靠马灯在床单后面投影。
- 来电，日光灯从床单前面打过来，把影子冲淡了，这是"电"打断了"戏"。
- 小满亲手关掉电灯，影子又回来了。

## 二、技术路线

全片在浏览器里用代码逐帧渲染：无头 Chromium + WebGL / Canvas，ffmpeg 合成，`tools/film.mjs` 按剪辑表 `js/film/edl.js` 拼片。不是录屏，也不是在剪辑软件里摆素材。

1. **床单戏：WebGL 光照引擎**（`js/lamp/`）
   - 床单影子是**物理计算的影子图**：马灯的火苗和玻璃罩当作两个大小不同的发光体，皮影离床单越远，影子越大越虚，贴近床单就变小变清楚。
   - 皮影是染色牛皮：背光看到的是透光的颜色，后台看到的是皮面。签子的影子从皮影往下伸出幕外。
   - 床单本身是面光源，照亮前面的小满和后台的人。还有空气散射、泛光和颗粒。
   - 人物是"卡片"：2D 图由轮廓算出法线和材质，再在同一套光里受光。后台马灯离人很近，所以用整身软法线，避免一节一节的浮雕感。
2. **屋内镜头：底图 + 人物图 + 程序打光**（`js/paint/`）
   - 背景和人物是平光的图。夜里的明暗全部由程序在线性空间里算光照图再相乘：日光灯、停电后的月光、马灯火苗的闪烁、手电光锥、手机屏光。
   - 火苗、屏幕、灰尘、烟这些自发光的东西单独叠加。
3. **道具和小动作由程序画**：
   - 道具：马灯、樟木箱、插座面板、手电、火柴、蚊香、吊扇；
   - 皮影：鹤、乌龟、布景；
   - 手机里的原创跑酷小游戏和充电界面。
   - 人物图拆层做小动作：拇指按键、小腿晃、胳膊三态切换、眨眼换脸。
4. **声音**（`audio/`）
   - 乐器是程序合成的：板胡、笛子、扬琴、琵琶、梆子、锣钹，以及 8-bit 和电子鼓。
   - 环境声和音效也是合成的：蟋蟀、吊扇、日光灯、火柴、插头、手电、木箱。
   - 按剪辑表自动对位混音，响度归一到 -16 LUFS。来电那一刻音乐整段切断。

## 三、创新点：光和影子是算出来的，而且在故事里起作用

- **鹤亮相（S15）**：鹤从远处贴近床单，影子由大而虚变得清楚。这是光源大小和距离决定的，不是手调的模糊。
- **小满第一次上手（S20–S21）**：她把签子拿得忽远忽近，乌龟影子就忽大忽小、忽清忽虚。笨拙是用光学表现出来的。
- **小狗追鹤（S26）**：手电是冷白的点光源，马灯是暖黄的。同一块床单上，冷的手影狗追着暖的皮影鹤：新玩法和老玩法在一束光里相遇。
- **来电（S27）**：日光灯装在床单前面，正面照亮床单，把背后透过来的影子压淡。剧本按这个物理关系安排了灯的位置（`docs/preproduction/script-v3.md` 第 0 节）。

主要转折（详见 `PROGRESS.md`）：
1. 3D 骨架人物 → 2D 卡通 → 剪纸片。
2. 改为"一盏灯照亮的世界"的光照引擎。
3. 人物改用 AI 生成的图，并在同一套光里打光。
