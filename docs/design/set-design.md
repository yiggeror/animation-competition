# 场景设计：堂屋

> 平面图与剖面：`docs/preproduction/floorplan.md`。光照状态：`renders/design/room_lighting.jpg`（全景 × 6 种光 × 3 个画风）。

## 这是谁的家
南方乡下（湖南）的一间老砖瓦房：两坡顶、露明的檩条和椽子、青瓦；墙抹灰刷白，下半截刷了绿漆墙裙（八九十年代的样子），水泥地。住了几十年：墙根发黑、墙裙掉漆、屋顶角落有水渍。年代是现在：有显像管电视（舍不得扔），也有孙女的智能手机和充电线。

## 物件（每样东西都有它在那儿的理由）
| 物件 | 位置 | 为什么在那儿 / 在故事里干什么 |
|---|---|---|
| 竹席 | 西边地上，紧挨插座 | 孩子要边充电边玩；夏天贴着水泥地凉快 |
| 手机 + 充电线 | 竹席上 | 第 1–2、10–11 场；线插在墙上插座 |
| 奶奶的小板凳、搪瓷盆、毛豆 | 竹席旁 | 剥豆时能看着孙女；毛豆壳越剥越多（第 10 场"一地毛豆壳"） |
| 八仙桌、长凳、西瓜、暖水瓶、搪瓷杯 | 中间偏东 | 吃饭的地方；那块没吃的西瓜一直在桌上 |
| 显像管电视、电视柜（两个抽屉） | 西墙 | 第 1 场开着没人看；第 3 场小满在抽屉里翻出手电；第 10 场消磁"嘣"一声、雪花 |
| 挂历（八月）、奖状（小满妈妈小时候的） | 西墙 | 生活痕迹；奖状说明"这家人的孩子在这间屋里长大" |
| 晾衣铁丝 + 木柱 | 北侧 | 平时晾毛巾和衣服；第 5 场搭床单 |
| 旧木箱（樟木） | 西北角 | 皮影一直收在里面；正好在后来的床单后面；第 9 场手电架在它上面 |
| 条台、座钟、暖水瓶、收音机、塑料花 | 北墙东段 | 堂屋的"正面" |
| 中堂画（松鹤，原创）、对联 | 北墙中间 | 松鹤和片中的鹤遥相呼应（不点破） |
| 大相框（一堆老照片） | 北墙 | 第 3 场手电扫过：年轻的奶奶站在戏台幕布后面，手里举着皮影（照片角上写着 1972） |
| 立柜 | 东墙 | 马灯平时放在柜顶 |
| 吊扇、日光灯、拉线开关、调速器 | 屋顶 / 大门左边 | 停电和来电的主角 |
| 蚊香 | 竹席边地上 | 吊扇转时烟被吹散，停了烟变直——"安静下来"的物理表现 |
| 扫帚 | 门后 | 生活痕迹 |

**主次：** 故事用到的东西（手机、西瓜、老照片、木箱、拉线开关、床单）放在主机位能看见的地方；其余东西颜色压低，不抢戏。

## 六种光照状态
1. **日光灯（开场）：** 平、白、有点冷；吊扇叶片在地上投下转动的影子；电视的彩光、手机的蓝光只照亮一小片。
2. **停电：只剩月光：** 月光从南窗斜进来，落在竹席北半边，带窗格的影子；其余地方很暗但不是全黑（眼睛适应后看得见轮廓）。
3. **马灯点亮：** 暖光从立柜旁一圈圈铺开，阴影深；月光被挤到窗边。
4. **搭台后：** 马灯吊在床单后，床单整片发亮，成了屋里最大的光源；屋子其余地方靠床单的反光照着。
5. **来电：** 日光灯从床单前面打下来——床单上的影子被压到几乎看不见；整屋惨白、平。马灯和手电其实还亮着，只是被盖住了。
6. **关灯后：** 回到马灯（加上一直开着的手电），吊扇还转着，床单轻轻起伏。
