# 画风方向

## 第四版（当前）：一盏灯照亮的世界

团队对第三版的反馈：人物自己也是剪纸片很奇怪；网上精良惊艳的画风很多，担心这个故事做代码动画没有优势；剪影人物看起来恐怖。
第四版的想法是：**代码动画的长处是光**——光从哪里来、被什么挡住、透过什么颜色、在空气里散开，这些都可以真实地算出来。
这部片讲的恰好是"一盏灯"：停电的夜里，只有马灯和被它照透的床单在发光，其余一片黑；来电时日光灯把一切照得又平又亮，魔法就没了。

- **光是真的算出来的**（`js/lamp/shaders.js`）：屋子按真实尺寸建模，每个像素从镜头射出一条光线求交。
  - 床单是一块面光源：亮度按点光源照平面的公式算（中间亮、四周暗，薄布透出火苗的一团亮芯，像月亮），上面的影子是物理投影；
  - 马灯在床单后面：看戏这边哪里能被马灯直接照到，取决于"点 → 灯"这条线有没有被床单、两边挂的被子、晾衣铁丝和夹子挡住；火苗和玻璃罩有大小，所以边缘有半影；
  - 光从布帘上沿漏到芦席顶棚上；空气里有薄尘，沿视线积分散射光，床单前有一层光晕，灰尘被逆光照亮一闪一闪。
- **人不是剪影：** 小满的脸迎着床单，被暖光照亮，眼睛里映着床单的高光；背光的一侧有屋里的暖色反光和一点月光，不会黑成一块。
  人物用 2D 设计（形状、颜色、五官都由我们设计），再由轮廓算出"鼓起来"的法线，参与同一套光照——是"有体积感的 2D"，不是 3D 建模。
- **皮影是画面里最鲜艳的东西：** 本色牛皮透出琥珀色，染色的地方透出朱红、青绿、黄，染黑的地方挡光，镂空的地方最亮；布景（荷塘、松枝）也是刻花染色的牛皮。
- **调色：** 琥珀金和深靛蓝；暗部不压死，胶片颗粒和晕光。
- 关键镜头：`renders/checkpoint1-v4/`（静帧 + 5 秒动态）。

## 第三版（剪纸片，已被第四版取代）：皮影 → 剪纸片 → 《来电》

第二版的 2D 画法（粗墨线、线条抖动、平涂暖色）和人物（豆豆眼、腮红）太像团队之前的 3am-bug、small-claude，团队指出后改从头设计造型语言：
**上海美术电影制片厂的"剪纸片"（《猪八戒吃西瓜》1958）就是从皮影和窗花发展出来的**，和这部片讲的皮影戏是同一条文化脉络。

- **人物：** 民间剪纸、年画娃娃的造型语言——圆圆的红脸蛋、剪出来的杏仁眼、扇贝边刘海、镂空花纹透出下一层的颜色。
  身体一片片铆接（像皮影），每片长度固定，只能绕铆钉转——**动起来不会被拉长、扭坏**。
- **同一组纸片，三种画法**（样张：`renders/checkpoint1-v3/`）：
  - **A 剪纸片：** 彩纸分层，纸边受光，层与层之间有柔和的投影，纸有纤维纹理；夜里是深蓝，暖光只落在被照到的地方。
  - **B 剪影：** 人和布景是深色剪影，镂空处透光（裙子的梅花、门帘的团花、眼睛），轮廓被灯光勾亮；背景本身就是光。
  - **C 工笔：** 细而匀的墨线勾整体轮廓，矿物色偏灰偏暖，边缘一层层渲染，绢的纹理。
- **建议：** 以 **A 剪纸片** 为主；停电后、马灯还没点亮的那几场用 **B 剪影**（月光里只剩轮廓），马灯点亮时纸的颜色一层层"亮"回来——画法本身跟着光走。
- 床单上的影子三种画法通用，都是按几何计算的物理影子。

## 第二版（2D 卡通，已被第三版取代）

### 2D 手绘，独特性放在光和戏台上

检查点 1 第一版的三个画风（下面保留）是在 3D 渲染的光照缓冲上换画法，本质上是"3D + 滤镜"，人物也是 3D 拼的。
团队看过后指出人物粗糙、3D 式的运动容易畸形、画风没有优势。第二版改为 **2D 逐帧绘制**：

- **人的世界：** 温暖的平涂手绘——一条连续外轮廓、线条每秒 12 张的呼吸、固有色 + 光照图 + 亮边。马灯、月光、日光灯仍然是有位置的光源，只是在 2D 里画。
- **戏的世界：** 床单是画面里唯一"自己发光"的东西；上面的影子按真实几何计算——放大 D/(D−d)、火苗和玻璃罩两种半影、彩色牛皮透光、签子影子越往手那头越大越虚。
- **来电那一刻：** 日光灯从正面把床单照亮，影子被冲淡、整个画面被冲平——温暖手绘的世界一下子变得惨白、平。这个反差是这部片自己的样子。
- 动作测试：`renders/checkpoint1-2d/`。

## 第一版（已被第二版取代，保留作过程记录）


三个方向共用同一套场景、人物、皮影和**同一套真实光照计算**——区别只在"怎么画"。所以无论选哪个，光从哪来、影子落在哪、来电时影子怎么被压淡，都是算出来的，不会变。

每个方向都有：第 6 场鹤亮相、第 10 场来电的样张（1920×1080），以及一段 4 秒的动态小样（第 6 场鹤亮相，正面：奶奶把鹤从灯前送到床单上，影子由大而虚变得小而清楚；小满从缩着到坐直；镜头缓推）。

## A「灯影」——用皮影的镂空纹样画明暗

**一句话：** 亮处是平涂的染色牛皮颜色，暗处整片沉成深棕剪影，亮暗之间用皮影的刀法纹样（月牙、鱼鳞、圆点、卷草、方胜）刻出过渡。

- 光越强，刻掉的越多；纹样贴在物体表面（墙是月牙，墙裙是鱼鳞，木头是卷草，地是方胜），镜头动的时候纹样跟着物体走。
- 人物身上用画面坐标的细点（关节处不会出现纹样接缝）。
- **来电时**：日光灯把所有地方都推到"亮"那一档——纹样、剪影全部消失，画面一下子变平。"惨白、平"不用另外设计，是这个画风自己的结果。
- **好处：** 和题材绑得最紧，一眼能认出"这是讲皮影的片子"；暗场不会糊（剪影衬着亮背景，轮廓清楚）。
- **风险：** 纹样要做得精致，否则容易像波普网点；人物表情在暗处会被剪影吃掉，近景要保证脸在亮档。
- **动起来的检查（已做）：** 墙、地、木头上的纹样钉在物体表面，镜头推近时不闪不爬；人物身上的细点是画面坐标（人物大幅移动时纹样不跟着走），动作测试阶段再看是否要改。

## B「刻光」——黑底木刻，光是刻出来的

**一句话：** 底子是墨黑，有光的地方用刻刀刻出排线；排线的粗细就是算出来的照度，刻线的颜色就是光的颜色。

- 墙上横刻、地面顺透视斜刻、人物 45° 斜刻；刀痕两头尖、有起伏、偶尔断刀——手刻感。
- 马灯刻出暖橙，月光刻出冷蓝，日光灯刻出一片均匀的灰白；灯本身周围刻出放射的光芒。
- **床单上的戏不刻线**，是彩色玻璃一样的光：人的世界是"刻出来的"，戏的世界是"亮出来的"——两个世界一眼分开。
- **好处：** 最有冲击力、手作感最强；光和暗的对比最戏剧化；中国新兴木刻的传统可以写进制作说明。
- **风险：** 画面信息密；温情段落要控制排线密度，避免显得冷硬。
- **动起来的检查（已做）：** 动态小样第一版查出墙上的刀线在镜头推近时会"爬"（线距按像素深度算，每帧滑动约 14% 线距）。已改为线固定在物体表面、两档线距按远近混合；相邻帧墙面差异从约 15 降到约 2.5，与 A、C 相当，线也变得笔直。人物身上的斜刻仍是画面坐标（避免关节处接缝），人物大幅移动时纹样不跟着走，动作测试阶段再看是否要改。

## C「绢灯」——一幅会动的绢本工笔画

**一句话：** 旧绢做底，铁线描勾形，矿物色平涂；受光处颜料透出来、偏暖金，背光处一层层罩墨和花青。

- 夜是蓝黑的（花青 + 墨），马灯的光是一层暖金色的罩染；床单是画里唯一"发光"的东西，像绢的背后点了灯。
- **好处：** 最雅、最安静，温情段落最舒服；表情和手的细节最容易看清。
- **风险：** 三个方向里最"常见"；热闹段落（第 9 场）的冲击力不如 A、B。

## 我的建议
- **首选 A「灯影」**：它让"光"和"皮影"成为画面本身的语言，来电那一刻的变化最有说服力，也最符合"只有这部片会长这样"。
- **B「刻光」** 作为强有力的备选：如果更看重冲击力和手作感，选 B。
- C 适合想要更安静、更好读的取向。

样张里人物还是第一版造型（设计稿另见 `character-design.md`），选定画风后会按画风重新打磨人物的线条和细节。
