# 人物设计

> 设计稿图：`renders/design/char_turnaround.jpg`（三视图）、`char_scale.jpg`（比例）、`char_expressions_xiaoman.jpg` / `char_expressions_nainai.jpg`（表情表）、`char_poses.jpg`（典型姿势）、`char_hands.jpg`（手）、`char_lights.jpg`（三种光 × 三个画风）。
> 设计稿用中性画法，只示形体、比例、服装、配色和表情；选定画风后按画风重新打磨线条。

## 小满
- **9 岁，城里来的孙女，约 1.30 米，约 5.5 个头高。** 头比真实比例稍大，远景也读得出表情。
- **轮廓：** 高马尾（红发圈）+ 一撮翘起来的呆毛 + 齐眉的碎刘海。马尾和呆毛是她的签名轮廓——第 6 场她背对镜头坐着看戏，只看后脑勺的剪影也认得出是她；它们也是跟随动作的来源（甩头、跑、瘫倒时都会甩）。
- **脸：** 大而黑的眼珠 + 一个高光；粗短、很会动的眉毛；嘴小但张合幅度大。性格靠眉毛和嘴的组合：嘴硬时眉压低、嘴角往下撇、眼睛斜着看；看呆时眉毛抬高、嘴微张。
- **服装：** 大一号的橙黄色短袖 T 恤（胸口一颗白色五角星，原创图案）、牛仔蓝短裤、光脚（鞋脱在竹席边）。夏天、城里孩子、坐不住。
- **手：** 孩子的手——掌肉、手指短而圆。比手影小狗时用"食指中指无名指并拢做上颚、小指做下颚、拇指翘起做耳朵"的手型；第一次比得手指散开、耳朵耷拉。
- **动作性格：** 快、急、幅度大、坐不住。打游戏时小腿翘着晃；着急时整个人往前扑；瘫倒是"整块倒下去"。

## 奶奶
- **七十来岁，约 1.52 米，约 6.5 个头高，略驼背但精神。** 不是可怜的孤独老人：她手巧、有本事、有幽默感。
- **轮廓：** 灰白短发往后梳，别在耳后（一枚黑发卡）；细圆框老花镜；略驼的背让她站着时头往前探——看东西时像在"打量"。
- **脸：** 眼睛细长，笑起来是月牙，眼尾有笑纹；法令纹、额头纹很淡。狡黠时一只眉毛挑起、嘴角斜着笑。
- **服装：** 浅蓝底碎花短袖衫（翻领、前襟一排白纽扣）、藏青黑的宽腿裤、黑布鞋白布底；左腕戴一只旧玉镯——近景里它会随手动而碰响。
- **手：** 长、瘦、指节突出（老人的手），动作慢而准。剥毛豆用拇指和食指捏；握签子时四指包住、拇指压上；握小满的手时从后面整只手包住小满的手。
- **动作性格：** 慢、稳、准，手上讲究；笑的时候整个身子都在笑（笑弯了腰）。

## 两个人放在一起
- 颜色：小满是暖的（橙黄 + 蓝），奶奶是冷的（浅蓝 + 藏青）——同框时一冷一暖，一眼分开；在马灯下两人都被染暖，来电后被打回各自的颜色。
- 节奏：小满的动作"一下一下"，奶奶的动作"一口气"。

## 三种光下（见 `char_lights.jpg`）
- **马灯：** 暖、从侧下或侧面来，阴影深；脸只亮半边。
- **手电：** 冷、硬、有清楚的边；光斑外几乎全黑。
- **日光灯：** 从头顶平平地照下来，几乎没有阴影——"惨白、平"。

## 技术说明（为什么不会有关节缝）
人物不是一块块拼起来的图片：身体是一个连续的三维形体（有向距离场的平滑并集），渲染时再画成二维。手肘、膝盖弯的时候外侧自然是圆的、内侧自然收拢；衣服是另一层形体，会跟着身体走。手臂和腿由两段式 IK 摆放，关节只会朝正确方向弯；手指逐节弯曲，拇指能对握。
