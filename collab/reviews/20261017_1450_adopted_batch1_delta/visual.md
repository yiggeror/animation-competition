# S01/S04 采用片：一页实际诊断（2026-10-17）

**结论：此版不应按“没有穿帮”争取通过。** 实际编码片缺的是可读的表演和反应；无明显断肢、接地点跳位只说明未发现这类硬伤，不等于动画效果成立。用户已否此片，应重做动作设计并补画。

## 1. S04：手停已做，缺的是鲜明停电反应

F0–62是电视特写；F63首次见奶奶，她已抬头，豆荚仍握在手里。**可见段手已经停住，未见继续摘豆；这点已实现。** 实帧中k05为较低头/下看，k06为抬头睁眼，k08为抬头方向的闭眼眨眼；三态都保留手持豆荚的停手姿势。缺的是可读的抬头看灯、转看小满及肩颈跟随反应，观众也未看到“正在摘豆→忽然停手”的过程。F96→108、F162→174是低头又抬头；F186低头仅3帧后F189又抬头，尾段形成缺乏动机的短促点头。小满也主要是嘴眼变化，手肘与手机基本固定，难读为更着急。

证据：`S04_g_boundaries_01–03.png`、`S04_x_boundaries_01–02.png`；原亮度全景 `overview_04–06.png`。人物接景、光点贴手成立，但不补足反应表演。

## 2. S01：奶奶的摘豆更像短手位切换

实际片可见捏豆、抬手、落向盆的手位，但几个关键手位仅3帧，夹在较长停留之间，例如F18→21→24→27、F54→57→60→63。缺少足够清晰的接触、用力、摘下、落盆、重新取豆的过渡和结果；快速切位又叠眨眼，动作意图不易读。不能只按表中换态次数当作表演充足。小满腿确有往返中间态，闭眼也确实入片；这仍不能证明连续观看自然。

证据：`S01_g_boundaries_01–02.png`、`S01_x_boundaries_01–06.png`。手机背面遮拇指、逐粒摘豆而非整荚剥净为已知限制，本报告不把它们新增成穿帮。

## 3. 字幕、画质与光影

确定错误：S01整段字幕仍写“推过来一块西瓜，小满摇头”，画面未演；s01.js也说明递西瓜已移S03，需更新EDL并重烧字幕。S04字幕建议改“电视特写→全景”，以匹配前63帧实际景别。原始证据 `frames/0001.png`、`frames/0288.png`、`frames/0289.png`。

本审片只有960×540，视频约0.95Mb/s；宽景中奶奶脸约30像素高，手部更小，细动作在最终编码里难辨。不能把插值放大当作高清证据。夜景手机光集中成亮斑，奶奶脸和手读法更弱。应由新版本同机位比例稿校准大小关系、加强可读的接触光与反应轮廓；本审未取得物理尺寸证据，不凭用户反馈反推某个精确缩放值。

## 4. 新版必检

1. 保留已成立的停手状态，补新图演鲜明的抬头看灯/转看小满与肩颈跟随；让首次见奶奶前后读到停电反应，避免只有短促低头回弹。
2. 摘豆按可见结果验收：手指接触和用力、豆的离荚/落盆、下一轮起手。各动作阶段要有可读停留和中间姿势，不机械增加张数。
3. 小满急按/凝神反应需从实际机位读得见；保住手机、双肘、衣摆与席面接触，小腿反向仍过中间态。
4. 同机位核祖孙比例、盆凳鞋接地；亮暗两场均检查脸/手，提供高质量原尺寸短片，避免靠540p宽景判精细动作。
5. 修字幕；重新审全部换态边界，并由有连续观影能力的人看原速节奏。此轮没有声称原速自然度通过，也未审核音频。
