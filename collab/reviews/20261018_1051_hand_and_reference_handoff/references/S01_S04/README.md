## 实际可用性与缺口

- 三视可锁身份：奶奶近左腕有镯、远右腕无镯；小满黄裙、红凉鞋、双辫。S01/S04奶奶朝左，小满头朝右。侧面三视本身朝右，不能盲目镜像后仍沿用原左右手。
- 小满旧趴姿母图是偏三分之四角度。横屏双手握持可见，屏幕侧两拇指的触点被挡住。背壳上的指背不能当作拇指触屏证据。母图只支持身份、可见轮廓和总体比例，新严格侧面握手机还要图审。
- 奶奶旧剥豆母图已是左手托开荚、右手夹出一颗豆，不是F0未开荚或F12首次掐开态。按0.205等比、近鞋底落y775后，臀衣接点比代码凳顶高约8.5px，不能直接贴回或非等比拉长。新画须坐实同一凳，并将盆底压在大腿衣料上。
- 没有证据证明旧母图本镜动作已获通过；更没有共用侧面初态、掐开/落豆、停电抬头的合格成图。线长一致不抵消手指穿模、盆悬空或身体厚度问题。

## 复用与时序

- 清单S04 F0原文是“同S01掐豆荚的一张”，没有逐字指定帧号。本包提议复用S01 F12，送参考门确认；不误接S01 F70末态。复用的是人物世界坐标与画层，S04仍用原固定全景相机。S01渐推近，不能将F12截图直接复制成S04相机。
- S01 F12先掐开，F28豆子离荚，F35入盆；F50伸手、F62夹稳新荚、F70低头看仍须展开，不能靠这六态跳过。小满膝/大腿支撑固定，只转小腿；F20近腿最高，F43远腿抬起，两手始终承重握持。
- S04 F7唯一一次全屋灭灯、双手与荚停住；F22头开始抬，F28嘴微张，F34到位。F7至F22之间眼先看上方是表演提案，未冒称清单精确给了眼动帧。头绕固定颈根转，躯干、臀座、双鞋、盆保持支撑。S05a F10不能再演一次全屋停电。
