# g01 奶奶：S01 / S04 接入候选子包

**可交 Opus 接入试渲；不是整镜/原速动作验收。** 本包只有奶奶，S01/S04 小满与镜头代码由其他作者/Opus接入。主仓未写入，S10未改。

- `assets/chars/`：8态×固有色/法线/材质，共24 PNG；k01是母版副本，也走同一prep。
- `assets/flips/g01_beans.flip.json`：S01，24fps，288帧，12秒。
- `assets/flips/g01_beans_s04.flip.json`：S04独立表，24fps，192帧，8秒。请仅S04选择此名；不要使S10套用S01表。
- `originals/`、`requests/`、`tool_outputs/`：母版副本与7张新图原件、实际请求、完整工具输出。7张各一次，都只用同一母版编辑，无派生图链式重生。
- `reports/S01_manifest.json`、`S04_manifest.json`：最终每帧选择/三图哈希；两次 `flip_manifest.py` 均exit 0。`package_verification.json`含prep与透明度验证；`originals_manifest.json`含原件哈希。

S01按原音频随机掰荚时点在F18/54/87/117/144/180/216/246给k03，随后摘豆、暂放；两次看女孩始于F63/F198。为回到实际掰荚声音，凝视比旧rig的1.3秒包络提前收回，见曝光表。豆粒的逐个落盆轨迹没有新增中间图，本组不宣称每轮剥净一荚。

时点独审指出k01–04是同类低头睁眼微笑，已按同类脸合并计算，不能以换手图冒作换表情。最终在F21/57/120/147/183/249摘豆时点使用k07短眨，另有两次抬眼中短闭眼；S01同类脸最长36帧（1.5秒），S04可见段最长27帧。眨眼频率因此比旧“2.5–5秒一次”通用建议更高，是为满足最新脸变化门槛的有限方案；原速自然度和远景是否能读到仍待实片。

S04 F0–62人物不可见。首个wide F63已经选k06停手抬头；F69与F135短插k08，各3帧，其余为注意力/握姿小变化，不重新开始剥豆。曝光记录明确第一项的`visible_from_frame=63`。

配准只用固定凳脚(538,1274)/(745,1215)，第三固定座角(759,884)独立检查，原图779×1355，新图951×1654。`anchors.json`七张新图第三点残差0.55–2.00母版像素，均≤3；分数0.681–0.874。实际看过凳/盆配准裁片。只做loader的全局相似变换；没有拉伸/局部变形来掩盖漂移。诊断配准图在`evidence/`，不作为可投影资产。

静态独审见`reports/independent_static_review.md`（character_audit），已确认7图无新增多手/错腕/明显断臂硬伤，保留k02/k04语义及k08短插限制。本包作者不把自检称独审。原母版k01盆后上沿已有少量alpha缺口，新图边线更完整；木纹/描线也有重绘，切换是否闪动待实际全景，不用Python补画。
