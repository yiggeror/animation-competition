# 三关键绘图门

A/F000：膝、胫、鞋背撑地，低跪、躯干前俯。两手张开未握；两长签由箱左窄沿支托，不能悬在空中。角色左手（远、玉镯）先下探捏上签，抬高杆柄分开手位后，右手（近、无镯）再握下签。鹤仍由箱内布托，先握不能先飞起。

B/F064：上/下签都合掌但尚未举。右掌点≈(930,765)，左掌≈(930,630)，腕比掌靠身体.23H。拇指/食指从杆两侧包拢，掌内短杆与代码两露出段是同一直线；其他指自然弯，不握方块拳。体块手只给接触关系，真指节/腕根必须实际母态另审。右/近与左/远身份从头到尾不换，玉镯始终左腕。

C/F114：髋小幅前上移到膝上，躯干/胸廓/肩/颈/整头共同回直；双膝、胫和足背保持接地。右掌≈(860,690)，左掌≈(790.3,539.9)。鹤身与颈按原铆点展开，整片由55°斜置转到85°近立；两根杆固定约1.774714H和2.684174H（场景空间约381.56px和577.10px长度尺度，非2D投影长度）。下签接body局部[-75,6]mm，上签接neck3局部[10,0]mm。取点直接来自实际makeCrane(1.35)/solve/pointOn，不吸到喙尖或用腕点代掌点。

画师只绘同一个奶奶：身份/衣装沿三视03与表情02，低髻细框镜、蓝白花衫、宽深裤、黑布鞋、左玉镯。源03两处颈影仍属参考草稿；04曾造成额/颈变浅，不能自动替03。旧g12的手/长前臂/混并裤褶不迁就；后脑、颈根与衣摆要按每张真实姿势重画。不要把这些灰色体块、实际代码鹤、长签、箱子、地影或灯光画进人物原生图。

暂定原生1024×1536，scene注册.75+(300,100)，只为目前三关键的画框提案；Astra冻结前不作为生产锁。构造坐标在原镜微推近前，整景只应用一次原cam。模型鞋底在末191帧推近后约留16.3px；实际原画仍必须看真实alpha边和实渲，不能借模型余量签收。
