**冻结：3次内置 image_gen，每态一次，无重抽、无中间帧。协调独审允许三张进入统一近景试接；未宣称最终验收通过。**

## 原件、时刻与尺寸

- `originals/S02a_k01_focus.png`：0.50秒 / F12，专注下视、闭口平线。
- `originals/S02a_k02_tense.png`：1.20秒 / F29，睁眼、抿嘴、颈缩肩紧。
- `originals/S02a_k03_relief.png`：2.10秒 / F50，肩颈松开、闭口轻撇嘴角。
- 24fps下F12精确；1.20×24=28.8、2.10×24=50.4，F29/F50为四舍五入标记，秒数为准。

三张均为**原生1672×941 RGBA PNG**。实际提示词要求1920×1080，工具未暴露独立尺寸参数。原图逐字节复制并验证，未缩放、补边、抠修或局部复制。实际SHA256见 `SHA256SUMS.txt`。

## 独审条件与后到入口变化

- 原小满身份可认：深棕低双辫、红绒球、分绺刘海/呆毛、黄白点泡袖裙和白圆领；表情三态可读，没有手机/手/背景。脸形、刘海边线与波点有轻微漂移，不声称逐帧完全锁定。
- k02紧张力度偏弱，主要靠眼睛和颈肩；需在实片中判断头下移→回升是否读为缩头，避免看成图层跳动。主体alpha≥128上沿原生y为77→137→115，不可把这当固定锚强配。
- 三张仍有脸/领/袖柔渐变，未完全达到2–3层纯平涂。下颏、颈、白领已烘淡蓝光。**不是中性平光底色。**
- 生图所用表/代码来源为 `fe2c20fbf80cc88dcb4574686095b54244226206`。冻结前协调转来新入口：`cb2e7d`把S02a镜头K14改为K19脸特写；原先“偏大/高”只针对旧fe2表，不能据此判定不符新版。
- 同时后到的新光照入口要求中性室内平光底色、2–3层形体，由paint只乘一次场景光、不叠法线。本批已结束，未再生成；现图淡蓝烘焙与该要求的差异交Opus试接评估，避免重复冷色照明。
- 已看全部三张原参考、每张原RGBA及灰/暗底真实alpha合成。以真实alpha合成为准，三张可作为透明条件候选：没有直览隐藏RGB所暗示的明显残底灾难；k01暗底颈侧仅很弱薄晕，远端杂点几乎不可见。大量alpha253/254不等于严重半透明。
