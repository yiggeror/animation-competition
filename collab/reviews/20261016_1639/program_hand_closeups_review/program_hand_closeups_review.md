## S08 点灯

### 实帧看到的问题

1. **F36 / 1.500s：`frames/s08_lamp/frame_037.png`。** 右侧手部 `(600,315)–(845,485)`；原像素裁切 `keyframes/s08_F036_hand_crop.png`。四指上缘是连续尖角/折片，下方又叠长条指边，掌部是一大片圆袋状面；各指段互相折回，却没有自然指节体积与前后关系。这里不是手指突然多了一根，而是已有五指投影后的轮廓与内部线条不可信。
2. **F40 / 1.667s、F42 / 1.750s、F44 / 1.833s：分别 `frame_041.png`、`frame_043.png`、`frame_045.png`。** 火柴已经到最近点，但火焰底部与灯芯顶部之间仍有空隙；随后灯芯自己的火苗按时出现。火柴火焰、灯芯光焰有相互接近并逐渐合并的视觉效果，但没有明确演出火焰触到灯芯的瞬间。这个问题属于动作目标位置/起火时序，不能拿更亮的光晕代替接触。
3. **F72 / 3.000s：`frames/s08_lamp/frame_073.png`，裁切 `keyframes/s08_F072_lever_crop.png`。** 手仍以同一姿态捏着完整火柴，夹持手指在杆头右侧约一根火柴长度之外。接近拨杆的是黑色火柴头。杆头下降、玻璃灯罩下降时，这只手并未松开火柴或改成按杆手势。
4. **F70–84 / 2.917–3.500s：`contact_sheets/s08_lamp_lever.jpg`。** 两个黑色端点上下错开着一起移动，手形一直不变。不能将代码注释中的“指尖挪到杆头、往下压”当成画面里已经有手指接触。若创作意图真是“用熄灭的火柴去压拨杆”，需明确这个意图并让接触成立；现成画面并未把这个替代动作讲清楚。

### 分项判定

- **静态造型：不通过。** 折片指节、长边线与袋状掌面比自然握火柴更像铰接片。
- **动态骨长：未发现伸长；姿态本身从头到尾固定。** 手的屏幕变化主要是整体位置，甩火柴也没有相应手指/手腕姿态变化。固定姿态不是动态自然的充分条件。
- **左右手：实际只显示代码指定的右手。** 未见镜头内换手或手指增减。不以顶部过时注释写“两手”作为额外验收门槛。
- **遮挡：火柴先画、整手后画；手指内部整指排序。** 火柴末端可以藏到手中，未确认其突然穿出掌面；但指段片状交叠仍影响可信度。
- **目标接触：点火与压杆均需重验。** 不将视觉近邻当作接触成功。

### 对应代码与最小修法

- `s08.js:140–150` 两次均固定 `POSES.pinch`，没有按杆专用手势或松夹过渡。手指中点对齐 `hold`；`hold` 在火柴头后方4.5×25=112.5设计像素。
- `s08.js:133–138` 最靠近灯芯的火柴头为 `wick+[14,-22]`；火焰底部又偏移 `[-4,-4]`（第165行），离画出的灯芯顶仍有约14最终像素的竖向差。起火由第117行固定时间决定，不由接触事件驱动。修法：先调整火柴方向及最近点，让火焰有短暂、可辨认的接触/停留，再让灯芯独立起火。
- `s08.js:136–145` 把 `head` 插值到 `lever+[6,-16]`，没有把指尖对齐拨杆。到位后，夹指中点距杆端约 **57.8最终像素**；杆端与火柴头中心相差约 **8.54最终像素**。后者是中心距，不能忽略两端半径、描边而直接当作8.54像素“空隙”。修法：在甩灭/退出或收起火柴之后，另行演出指腹到杆面的短按，或者明确采用火柴杆压杆并严格对齐接触点。
- `hand3d.js:40,80–86` 的 pinch 目标对成人比例超可达约1.896模型单位，但末端重建保持骨长；不是游戏片的伸长错误。重定可达的、为细杆/火柴而设的实际捏姿，先检查一张静帧，再复验移动。
- 手模型的二维管状轮廓与整指平均深度限制见下文共用问题。应减少折回段之间不合理的尖角片状边线，建立真正的指腹夹持与掌肉过渡。

### 实帧看到的问题

1. **F36 / 1.500s 与 F60 / 2.500s：`frame_037.png`、`frame_061.png`。** 握持手 `(385,165)–(510,330)` 是一块大拳套状掌背，顶上露一排小鼓包，拇指和绕筒的指段几乎无法辨识。手电位于整手之后。这里不能简单认定“缺指”，但握持与控制开关所需的关系没有呈现出来。裁切 `keyframes/s09_F060_grip_crop.png`。
2. **F58 / 2.417s 与 F63 / 2.625s：`frame_059.png`、`frame_064.png`。** 第一次推开关前后，握持手形与位置相同。开关右端附近可以看到细小几何变化，但没有手指推进或回收。原代码证明这并非采样漏过某一帧：整个第一次推开关包络内手指关节都未变化。
3. **F74 / 3.083s、F84 / 3.500s：`frame_075.png`、`frame_085.png`。** 拍打手的掌部来到灯头上方区域，因此不写成“整只手完全没碰到灯头”；但四根伸直的手指长条横叠在握持手与筒身前，拇指在右侧独立向下垂成钩片，接触面和受力位置难读。F84原像素裁切 `keyframes/s09_F084_slap_crop.png`。
4. **F70–94 / 2.917–3.917s：`contact_sheets/s09_torch_slap.jpg`。** 两次拍打主要是同一张平手形上下平移；两次敲击的节拍有做出来，但遮挡重叠与接触姿态没有随击打调整。拍完之后手电自己亮起，握持拇指仍没有可见第二次推进。

### 分项判定

- **静态造型：握持手与操作关系不通过；拍打手也需针对接触重新摆姿。** 不把“手背遮住大多数指头”本身当错误；错误在于此镜头需要读到拇指推钮、绕握、另一手拍打，而这些关键部位读不出来。
- **动态骨长：未发现伸长。** 左手固定 grip、右手固定 flat，scale=0.8；运动是刚体旋转/平移。
- **左右手：左手 `side:-1`、拍打右手 `side:1`，无交换。** 左右结构没有随拍打翻转。右手指甲可见，不能因为手指朝左就判成左右反了。
- **遮挡：手电先整物绘制，左手和右手依次覆盖。** 无手指分段与手电共享深度。右手指在左手前的画层顺序稳定，但物理接触关系不因此自动成立。
- **目标接触：推开关动作缺失是确定问题。** 拍打已有落到灯头区域的整体路径，但需消除手指对另一手的大面积压盖，明确掌面实际落点与抬开。

### 对应代码与最小修法

- `s09.js:69,73,76` 算出两次 `sw`；第93行只传给手电绘制，第90、94行一直用同一 `POSES.grip`。`A.sw` 没有作用于任何手指关节或指尖。这是开关有位移、手没有动作的直接原因。
- 首次推钮时间内，握持拇指末端复算约 `(448.40,209.12)` 最终像素；开关中心从 `(456.72,195.59)` 移到 `(480.45,193.68)`，位移约23.8像素，拇指不跟随。这些点用于说明相对运动缺失，不能把中心距直接认作皮肤间隙。
- 修法：先在同机位把左手转到能清楚看到拇指指腹压住推钮、其他指段绕到筒后的姿态；给 `sw` 配套固定骨长的短拇指推进/回收，按钮与指腹共享接触轨迹。不能只把拇指强行绘到最前面来掩盖错误姿态。
- 第98–102行拍打手固定 flat，仅靠 `raise` 平移。应为落掌前、落掌、抬离设置少量腕/指关节变化，并把接触掌面与灯头位置对齐；调整指向，避免让长直指横压握持手成为主要视觉。
- 左手不必强行露齐五指；保留足够可见的拇指、侧缘弯指与筒身遮挡，就可以读出真正握住。不要为了显手指数量继续堆轮廓线。

## 共用手模型：确认项与限制

### 1. 骨长约束已与游戏版不同

`hand3d.js:65–68` 四指以固定节长依次旋转得到关节点；`80–86` 拇指在截断求角距离后用固定l2重建末端。S06全192帧复算所有骨段固定；其余三个镜头的姿态/缩放固定，也不存在目标推动骨段伸长的路径。

诊断输出：`analysis/pose_geometry.json` 和 `analysis/s06_bone_lengths_all_frames.json`。结果没有替代看片，也不代表已解决静态形状。

### 2. 通用预设不等于道具专用握姿

pinch 拇指目标超可达，末端保持骨长但并未到达目标；四指采用同一组固定弯曲，投影后出现片状尖角。grip 在S09和S12又与完全不同直径/方向的物体共用。应针对插头、火柴、手电、细杆分别约束静态接触和可见轮廓，而非继续靠一个中点/掌内锚点平移。

### 3. 2.5D轮廓与深度没有物理自洽保证

`hand3d.js:98–122` 用投影后的点与屏幕宽度生成整根管状轮廓；`155–162` 掌部用凸包；`171–175,233–238` 用整指平均深度决定掌前掌后。近节/远节互相折返、同指绕道具、指根与掌肉融合，都不能靠这套整指画层自动解决。

这些机制与实际折片/掌团问题吻合；没有重渲对照实验，因而不把某一条内部边线精确归因于某个单一函数。最小修复可以是此机位专用的合理分层造型，不要求为四个短特写先建设完整通用物理手系统。

### 4. 指甲可见性镜像有具体错误

点坐标用 `-side*x`（151行），指甲背面法线却用 `side*up.x`（209行）。S06拇指最明显：按几何正确方向 z≈0.909，实际判定z≈0.103，被0.15门槛隐藏。应统一变换并复验左右手的甲面朝向。此问题会削弱背掌识别，但不是全部手形缺陷的替代解释。

## 返工优先级与复验清单

1. **先S06：** 可信静态夹持、统一插头/插座空间方向、真正对孔、松手。保留光照与节拍。
2. **S09：** 让拇指确实推开关、明确左手绕筒及右手落掌位置。它是目前最直接的“物体动作有了，手动作没有”的镜头。
3. **S08：** 重定细物捏姿，建立点火触芯和压杆的明确接触顺序。
4. **S12：** 在当前手部特写范围内露出足够的夹杆接触区，修可见角状轮廓，再复验；不升级为整镜严重骨骼变形结论。
