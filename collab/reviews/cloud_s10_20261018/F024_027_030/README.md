## 实际绘图与来源

- **024**：以锁母眼眉局部作为唯一输入，实际生成眯眼稿；回图登记在原件目录。按镜框／鼻梁配准，只采眼内及眉额区域。头、耳、发、颈、衣全部保持母态。实际眼裂收窄，镜框不缩；同次回图修正了眉内侧接片小残点，没有再调用生成。
- **027**：首版是明显较大的三分之四转向，不作起转中间态，原件与退回理由保留。第二次从合格024重画更早的整头中间，首版只作为“过大”的反例输入，没有从失败姿态批量派生。新颅体、发际／盘发、双耳露出、下颌、镜架和真实颈面整体改变，不是把旧五官横移。实际双眼视线随避光偏画右，未命中提示词的左视目标；作者判断仍读成避光，可作为中间态继续030，此表演差异明确交Astra复审，不写成全部提示目标已达。
- **030**：从自审后的027实际候选派生，继续转向，近耳／镜腿更清楚、远耳更被遮，双眼压成带少量虹膜的窄缝，嘴轻抿。没有只扭脸或用代码算人物姿态。

10°／22°仅为设计目标，不作实图角度实测结论。024→027转幅、视线换向及027→030的节拍需要看实际曝光；三张存在不等同后续峰态或5秒全镜自然度通过。

## 固定下胸和真实头颈

027／030只作一次按衣胸定位的整张等比配准，未对头／脸作非刚体变形。实际新头、发、双耳、镜架、下颌与颈肤均取自新画稿。采用掩码包含整头和新旧下头／颈肤轮廓的并集，旧轮廓移开的地方也会清除，防止强锁旧发耳颈而只扭五官。外侧衣肩保留母态作为连接锚。

三态的 **y948–1079全部RGBA与锁母逐像素相同**，新衣带完整保留；024眼眉掩码外也逐RGBA相同。半透明细发、左红珠和主体253／254 alpha保留，只去孤立弱alpha颗粒及外缘少量彩色污染。接回时退掉了会造成领外缺口的矩形掩码做法；现采用真实皮肤／发轮廓，不取旧脸替新头。领外缘仍有少量绘图线条粗糙，请结合 `qa/*head_neck_native.png` 和实际解码原尺寸图看，未以文件数或数值门代替图审。
