## 固定骨长与投影的边界

使用前期已提出的左右同长构造包络：源等效U370/F335，乘0.9后为U333/F301.5场景像素。它们是“固定的假设长度上限”，不是测出来的真实三维骨长。肩/腕的可见二维投影允许缩短；每段的sqrt(L²−lxy²)只作为存在某个深度分量的可达见证。没有相机内参、身体深度和真实桌面深度，不能把这个见证冒充三维重建或无碰撞证明。

肘使用同一向下分支，保持在桌面上方的投影，并约束回收时不要向后炸开。左右手与道具的终端接点独立于腕关节。骨架通过表示中心线可达；最终仍须用成图检查袖口、皮肤轮廓、手指厚度、远近遮挡和桌/灯的真实接触。不得因数字通过跳过视觉审查。

## 不能再照抄旧图的地方

- 玉镯属于解剖左腕，本镜是远侧托盒/提杆手；近侧右手持柴，永远无镯。旧32图的近右腕玉镯错误，保留原始证据但不传给生产。
- F0–12把盒/擦柴区上提到中心(932,840)，以便近右手和擦皮接触都在桌沿上方可读。原代码盒中心约(932,869)，不是强制沿用值。本提案保留F17落桌位置与盒尺寸；F3药头确切落擦皮，F5划出后才起火。
- F17盒已归桌。先托到桌面，落定时左指改为触盒左边沿，随后离开；不让掌心夹在已落桌的盒底与桌面之间。F20向杆端伸手。
- F23左指先扣住杆端，F25带杆与罩上移，F27到顶。F23–77持续持有，F78是开指起点而非瞬间失去左手。这里不能握错提梁或调芯旋钮。
- F41药头碰黑芯帽，独立芯火仍为关；F43独立芯火必须已经有根地附着灯芯，再到F46撤右柴。蓝色芯火标注与橙色柴火是不同光源，不是“合在一起看起来亮了”。原代码1.8秒/F44才起的阈值已明确拒用。
- F53柴火灭且冒烟，芯火继续。F66柴由桌支撑、右指已松且右手回收；不可继续按旧2.8秒/F68才交接。
- F78开指，F79补充间隙核查且罩仍在高位，F80手已离杆且玻璃下降，F82落座。灯身和灯芯不跟着罩位移；左手不会被落罩拖走。
- F88–96身体坐回，胸衣纹跟着躯干；F106嘴角起、F114笑开、F122眼先往画面左看小满，不能把头提前翻到正面。
