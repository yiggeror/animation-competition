## 原样标准处理与隔离

脚本快照来自d0fa610：`prep_flip.py` → `card_maps.py` → `card_soft.py`，未改脚本。所有执行cwd均为本`probe_work`，没有在仓库cwd执行。

两份输入都是已有RGBA，按标准透明分支处理：alpha=round(clip((alpha−6)/(247−6),0,1)×255)，也就是≤6清零、≥247拉满，中间线性映射；RGB保持输入每个像素不变。随后标准材质图与整体柔和法线生成，未贴回母图凳/脸、未做补画。六张图均1024×1536 RGBA，同态三图alpha逐像素一致；核验见`reports/verification.json`。

`inputs`仅是本机指向既有母版/原件的相对软链接，不要求复制成仓库依赖；实际接景只需六张派生图和一张flip。`COPY_MAP.json`与`COPY_PATHS.txt`列出相对于`s29_grandma_prepare`的完整源路径及对应仓库目标路径。由主协调提交collab后交Opus决定是否复制/接景，本包未自行修改仓库。
