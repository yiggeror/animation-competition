# 《来电》S06 插座程序手部实际片复核

日期：2026-10-16。固定仓库提交：`6864560d82c83e10014a6f2ed24cfe4fa0628167`。本报告只审既有手部特写，不要求补完整人物或跪姿；没有改图、生图、改源码、重渲或外部发布。

## 可直接用于项目反馈的结论

**S06 暂不通过。手部虽未复现游戏镜头的骨段拉长错误，静态握姿仍明显不可信：拇指像一根从很低的掌侧伸出的斜长条，虎口与掌根缺少清楚的过渡，四指压成层叠薄片，掌部呈过大的袋状体块。拔插大部分时间只是这只固定形状的手跟着插头平移和转动。松手时虽然各骨段长度保持不变，手形仍未建立可信的“捏住方块后放开”。**

**另一个独立阻断项是插入方向：正视面板的两个上孔左右排列，插头的两片插脚却上下排列、一直朝画面右侧伸出，最后沿画面横向平移并消失，只覆盖左孔附近。当前“插回去”没有建立同一投影里的真实对孔关系。**

最小返工限于：为这个角度重定握插头的静态手形与接触姿态；让插头、手和插入轨迹共享一致的三维朝向；修复手指/手掌/道具遮挡及拇指背面朝向。保留既有墙面、光照与动作节拍。不能只补阴影、缩短一条线或盖住右孔就放行。

## 按检查项定性

- **静态造型：不通过。** 长条拇指、巨大掌团、指片层叠、腕掌转折与虎口关系均需要重定。不存在“只因代码写了真实比例就已正确”的依据。
- **动态骨长：本轮未发现游戏镜头那种越界伸长。** 对192个时间采样复算，所有五指的三节真实长度固定，误差约为 `10^-15`。S06 的拇指三段为 3.276、2.418、1.950（缩放后的模型单位）。此结论只说明骨段长度约束成立，不等于最终轮廓合格。
- **左右手：代码一直用 `side:1`，几何保持同一镜像支。** 未见途中换手。画面因掌团、无拇指甲等线索而背掌辨识差，但不将其写成已证实的左手冒充右手。
- **遮挡：道具与整手没有共同深度。** 插头先画、整只手后画，整根手指按平均深度排序；不能让同一根弯指的前段在道具前、后段在道具后。该结构解释了手指像贴在插头前的层叠片状物。未将所有轮廓交叠一概命名为“穿模”。
- **接触：中点跟随有做，指腹/夹持/插孔约束没有完成。** 两指中点锁定在插头后部是明确的已有功能，但不表示真实夹持。终态对孔错误是独立、可直接看见的动作问题。

## 代码和数值证据

全部代码均由固定提交 `git show` 导出到 `source_6864560/`。这些文件与影片同存于该提交，本轮没有执行原渲染器复现整片，不据此声称已证明每个像素的生成溯源。

### 1. 此版拇指确实约束了末端，不应套用游戏片根因

`hand3d.js:80–86` 对用于求解的距离截断，并在第86行用长度 `l2` 从IP关节重建真实末端。因此与游戏 `phone.js` 中“求角距离截断、绘制仍使用越界原目标”的错误不同。

但 `POSES.pinch` 的目标 `[2.6,13.4,-3.0]`（第40行）超出可达范围：S06 scale=0.78 时实际尖端与目标相差约 **1.479模型单位**。真实拇指骨长保持不变，代价是姿态被推到近直伸极限、尖端够不到设定目标。两实际尖端在3D中相隔约 **3.307模型单位**，投影中相隔 **74.117设计像素，即55.588最终像素**。

这些数值不是“多长就一定丑”的独立解剖标准；它们用于解释已见的长直拇指，以及为何不能把名为 pinch 的预设当作已经捏合成功。

### 2. 只用两个指尖中点定位，且同一姿态维持到6.7秒

`s06.js:91,114–123`：6.7秒前 grip 恒为1，固定 `POSES.pinch`；旋转/平移跟随插头。`gripAt = [pos.x+34, pos.y-6]` 仅约束指尖中点，没有分别约束两个指腹落在插头相对面。松手只把预设混合到0.55握度，然后整手退出。

### 3. 拇指背面可见性使用了与几何相反的x镜像

`hand3d.js:151` 的点变换为 `R([-side*x,y,z])`，而 `hand3d.js:209` 判断指甲可见性为 `R([side*up.x,up.y,up.z])`。S06 基础握姿中，同一拇指背面方向按几何变换的 z 约 **0.909**，实际用于可见性门槛的 z 约 **0.103**，低于0.15而隐藏指甲。

这是一处具体朝向不一致，应修正后复验；不能声称画上指甲就能修好整个手形。它也不能推出左右手在片中发生交换。

### 4. 投影后画管状手指与整指深度排序，不能处理弯指的局部互遮

`hand3d.js:98–122` 先把骨点投到二维，再用每段屏幕宽度构成一条平滑管；`171–175,233–238` 只用整指平均深度把整根手指放在掌前或掌后。弯曲/缩短后的多个段可以重叠，当前没有局部段深度、物体遮挡或针对该镜头的手形修正。`155–162` 的凸包掌部也不能独立保证虎口/掌肉形态。

### 5. 最后回插坐标明确不对应上排双孔

面板上排孔中心：`(1202,498)`、`(1278,498)`，来自 `s06.js:40,50`。终态 `d=0,lift=0,turn≈0`，插头 pos=`(1074,498)`，身子画到 `x=1202`。插脚局部从 `x=128` 朝正x伸出，两根轴线为 `y=-38` 和 `y=+38`（`57–66`），变换后为 `y=460`、`y=536`，不是双孔的共同 y=498。`pinsOut` 只是随着 d 归零而消失，没有插入墙面法线的三维旋转。

换到最终960×540画面（不计终态微小震动）：上排孔中心约 `(556.5,253.5)`、`(613.5,253.5)`；两插脚轴线为 y≈225、282，实际沿画面右侧移动。F152–154 的原帧正显示这个过程。

## 最小修法与复验门槛

1. 先固定最终机位，用一个静态握插头姿态建立可信的掌、虎口、短拇指轮廓与少量露出的弯指。可以保留固定骨长求解，但要把目标放回可达且保留自然弯度的区间；不要再把超可达的通用 pinch 直接套到道具中点。
2. 给插头和手使用同一空间方向：拔出沿墙面法线，查看时才转动；回插前先转回对孔方向，再沿法线入孔。或整体改成与插头侧向一致、孔位也同样投影的侧机位。最终机身应合理遮挡同一对孔。单纯盖掉右孔不能解决错向。
3. 分别约束拇指腹与对侧指腹到插头两个相对面；引入道具与指段的前后层次，或对此固定机位做明确的分层手形。不要只算夹指中点。
4. 统一指甲/背面法线与几何镜像，修复可见性；再精简内部边线、调整掌肉与腕口的过渡。照明留到这些结构成立之后。
5. 用 F12、F36、F84、F150–157、F160–178 对应动作阶段复验：静帧先成立；整段骨长稳定；夹持随动无浮移；回插真正对孔；松手有自然指腹离开过程。无需补完整跪姿。
