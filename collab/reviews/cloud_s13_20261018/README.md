## 比例、完整头颈与层次

三视图正面实心发顶 y≈64 至下颏 y≈224，取 H=160px；呆毛不计。上臂约 134.4px=0.840H，前臂约 109.9px=0.687H，腕至指尖包络约 61px=0.381H。肩骨宽约 110px=0.688H。肩、肘在袖下，为人工估计，误差约 ±8px；腕约 ±4px。全身约 5.6H 仅用于身份比例核对，近景不重造画外腿。

新角色画布提案 1024×1536、H=640px，整体置入原镜的 `source×.85+(330,−30)`，场景头高约 544px。画幅底对应源 y=1305.88；肘约 y=1668、腕约 y=2092，均在画外。JSON 同时列出固定模型的三维点、源画布二维点和场景点；透视 / 投影可以缩短，上臂骨长不能为凑坐标伸缩。

构造以枕骨关节连接颈根，不绕嘴或领口做纸片旋转。头 yaw 从 +35°到确认态 +42°，哈欠后段保持约 +24°直至F084，F087首次转到约 +8°，末段转到 −36°再落回 −33°；胸只从 +12°跟到 +4°。角度均为设计目标，**不冒称成图的精确实测角**。哈欠允许下颌下降约 0.055H，不能把上半颅或嘴贴图纵向拉长。领口接颈根，颈肤接下颌；整个头部，包括耳、发根与颈面解锁绘制。

躯干近臂始终为画左角色右臂，远臂始终为画右角色左臂；胸未越过正面，故两臂关系不换。**头越过正面后，头的近 / 远耳和马尾交换**，与近 / 远臂分开判断。JSON 的点名保留初态身份，另有逐态 `head_frontmost_ear_landmark` 指明当前近耳。耳被遮住不等于缩小耳骨，近耳也不能越画越大。

本版两手自然下垂、全程画外，没有手嘴接触、持物或第三只手。若审查认为必须捂嘴，先增加完整肩 → 肘 → 腕 → 掌路径、手唇接触近图和新曝光，再开画；不能从画外突然补一只手。
