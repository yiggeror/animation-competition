# 拉绳 v1：手部与造型第二独审

**结论：握放及手绳遮挡的局部技术机制可保留；闭握造型仍偏钩指，正式小满造型兼容不通过。本报告不代替完整动作、重量感或原速观感验收。**

## 可保留：连续握放与遮挡

- F26–30（1.083–1.250 秒）：手指由伸直经过横伸、屈折到闭握，有中间轮廓，未见一帧换成另一只拳头。主要屈指集中在 F27–29；这里只确认存在连续变化，不据此评价正常速度是否细腻。
- F30–44（1.250–1.833 秒）：绳从掌上进入、在掌指区被遮住、掌下重新出现，未见明显从掌面贯穿或握点脱离。下拉时手、绳端保持同一接触关系。
- F45–49（1.875–2.042 秒）：指尖连续展开；F52–53（2.167–2.208 秒）开掌与绳端清楚分离，不是手掌持续黏绳回去。

证据：`v1_close_consecutive.png`、`v1_hold_consecutive.png`、`v1_release_consecutive.png`。均从实际 PNG 裁切后最近邻放大；`v1_frame_evidence_sources.json` 记录各帧 hash、时间与裁切坐标。局部裁切围绕手掌移动，不能据此单独判断全身重量或世界坐标运动。

## 仍需改：手形可读性与正式角色一致性

F28–45 的指端向下垂钩，拇指与其余弯指的对握关系弱，更像钩住绳而非紧攥绳。没有发现新增手指或手掌断开的明确结构错误，但“像手”还不足以称自然好看。若按 root 已授权的 v2 小修，优先把折指收向掌内、使拇指压住折指，保持现有绳轴和遮挡。不要为修形改成一帧换拳。

当前 v1 已改白点裙、去红腰带，这两项已从 baseline 的差距中关闭；薄底红鞋也比 baseline 更接近。剩余差距仍明显：头脸占比大、横向扁宽，黑豆眼和圆片红腮，发束像平剪纸片；正式小满是较有体积的儿童脸、大棕眼、红绒球双辫。不能用数值骨长恒定或接触稳定掩盖观众会读成另一套人物的问题。`v1_vs_identity.png` 为当前冻结帧与正式身份的诊断对照。

## 范围限制

只认可这个侧面拉绳样片中的局部技术证据，不外推走路、转面、翻身或整片。未审整体重量感、腰缝修复、世界地面和最终正常速度表演。即使 v2 关掉钩指问题，也仍需独立面对正式造型差距。未修改仓库、未生成新图；仅在本审查目录写来源记录和诊断图。
