## 动作缺口与四根签的固定身份

最新剧本第8场和批准清单都写“奶奶把乌龟交给小满”，而 `js/lamp/shots/s20.js` 首帧小满已经握着两根龟签，奶奶同时分手持鹤。代码没有交接过程。本提案在0–2.4秒内补真实交接，不能把旧首帧当作交接已经画好的证据。

| 签 | 偶端不变量 | 初始／交接 | 稳态操偶 | 笑时 |
|---|---|---|---|---|
| T_H（青） | 龟head `[20,0]` | 奶奶R → 双方支持 → 小满R | 小满R | 小满R，CAMG画外 |
| T_S（粉） | 龟shell `[0,40]` | 奶奶R → 双方支持 → 小满L | 小满L | 小满L，CAMG画外 |
| C_B（绿） | 鹤body `[-75,6]` | 奶奶L暂并双签；R腾出后接C_B | 奶奶R | 奶奶R |
| C_N（橙） | 鹤neck3 `[10,0]` | 奶奶L | 奶奶L | F132–143送入R并夹牢后，L才离开 |

交接采用“受手先闭合、送手后松开”。开始奶奶L暂并鹤双签、R递龟双签；龟的两签都被小满握牢，奶奶R才撤回并接鹤身签。笑前R保持C_B，L把C_N送进R虎口，拇指与屈指均压住两杆之后，L才扶腹。每根杆仍有独立的轴与接触带，不能用两个计算握点同坐标代替画内真实的双杆包握。旧g20_laugh只清楚画出一截短签，见实际裁片。

L/R为角色自身手别，不按屏幕左右、高低命名。CAM20与CAMG的原几何位于人物左侧；奶奶近侧L应带镯。旧右向原图本身L带镯，但二维镜像不交换肩袖遮挡关系，不能沿旧镜像的近侧裸腕结构。K01小满转向奶奶时R可成为近臂，K02转向幕时L成为近臂；由完整肩—肘—腕链确认，不能随手位高低换手别。

源码 `T.cross ? i : 1-i` 会改变哪只手连到龟的哪个偶端。本提案不沿此作人物动作：R始终T_H、L始终T_S，绞签用真实硬杆交叉与前后遮挡。这里只列出后续接景须处理的映射缺口，未改任何场景实现。
