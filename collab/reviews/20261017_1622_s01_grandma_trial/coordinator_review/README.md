- f02：实际为闭眼线，镜框完整；手上两豆和荚姿不变。
- f03/f04：实际有头向左的转移、视线略下和闭口微笑；近裁未见三红珠变数/新多指/双镯。视线在实际镜头里是否落在小满头上仍需接景。
