## 身体与局部可达

F000沿S01/S04共用坐姿支撑：臀接点(933,691.9)，双踝(869,758)/(879,758)，鞋底775。F018身体、髋膝、双踝与六态包逐点不变，只改盆和双臂。F000不额外照抄旧代码的收脚，需与补门一并确认。

两臂采用同一IK分支，避免从自然端盆肘直接跳到旧F018反支。19个局部构造样点上臂64/前臂58一致；肩腕距离64.08–113.63，均低于122。F008/F016只在JSON列可达样点，尚未冻结它们的身体、节拍或生产姿势，不能据此声称全部首10态参考已完成。

必须保留的成图检查：F018近肘与近膝中心投影仅约5.6px。近臂要在膝外前侧、远臂在后，不能穿进裤腿或画成两臂共肘。坐姿臀部/衣下髋膝及真实袖厚未画，数值可达不证明体积、承重或连续自然度。若该遮挡门不通过，先改局部参考再开画。红虚线保留旧F018肘与浅盆沿作对照。
