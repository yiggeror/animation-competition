# 人物设计

## 第四版（当前）：有体积感的 2D，被灯照亮
> 程序：`js/lamp/xiaoman.js`（小满）、`js/lamp/cards.js`（由轮廓算法线）；造型检查：`renders/checkpoint1-v4/xiaoman_design.jpg`。
> 第三版的纸人被指出"人物自己也是剪纸风很奇怪"，剪影又"看起来恐怖"，第四版改为接近真实孩子比例的 2D 人物，放进真实计算的光里。

- **小满：** 头约占身高的五分之一多一点（不再是大头娃娃）；侧脸：圆额头、小翘鼻子、微张的嘴、圆下巴；大眼睛带两三根睫毛和一个映着床单的高光；
  红脸蛋；齐刘海分成几绺、头顶一撮呆毛、耳后扎辫子系红绒球；黄色连衣裙（小白点）、泡泡袖、白色小圆领；红凉鞋。
- **画法：** 每块形状（脸、头发、刘海、耳朵、胳膊、手、袖子、裙子……）先填固有色、画五官和花纹，再由轮廓做距离变换，离边越远"鼓"得越高，得到法线。
  边上的法线是横的，被侧光、逆光勾出亮边；中间朝着镜头。脸的法线往她面朝的方向偏一点，迎着床单的光。皮肤的暗部带一点暖（皮下散射）。
- **第 6 场的姿势（第三稿，2026-10-16）：背挺直坐在小板凳上，双手搭在膝盖上，抬头看。** 第二稿"手肘撑膝盖、托着脸"的姿势逼得人驼背，
  团队和合作 AI（Astra 团队）的评审都指出它读成"趴着撑住自己"，不像在看戏。这次先定外形——骨盆坐稳在凳面上、胸在骨盆正上方、肩放松、
  脚平放在地上稍往前伸——再用骨长把关节连起来，不再用"手肘落在膝盖上"去反推身子前倾多少。
- **手顺着膝盖的轮廓搭上去：** 手腕在大腿面上，手背拱过膝盖顶，手指沿膝盖前面垂下来。从外侧（小指那边）看，大拇指在膝盖里侧看不见；
  中指最长、指尖在最前面，无名指、小指离我们近、贴在膝盖侧面，指尖一个比一个短。整只手是一块轮廓，手指只用很淡的线分开，不画成一根根圆条。
  手肘由手和肩的位置定（朝后下方、自然弯一点）；任何时候肩到手腕都比两段骨头加起来短，手臂不会被拉直锁死。
- **比例按 9 岁女孩的人体尺寸**（约 1.32 米，头放大到 1.18 倍，站着约 5.8 头身）：上臂 20、前臂 16、手 12.4、大腿 29、小腿 26.5（膝到踝）、脚 18 厘米。
  脖子短而粗（孩子的脖子），四肢肉乎乎、膝盖不尖；睫毛只在眼尾画两根短的（不画成化了妆的长睫毛）。
- **四肢是一笔外轮廓，不是管子拼的**（团队指出：关节像人偶、手像戴手套、腿像"安"在裙子外面的零件）：
  - 整条腿：大腿面 → 膝盖骨 → 胫骨 → 脚背 → 脚趾 → 脚底 → 脚跟 → 跟腱 → 小腿肚 → 膝窝 → 大腿底面，一条连续的轮廓；
  - 整条胳膊：三角肌 → 肱三头肌 → 肘尖 → 前臂 → 手腕 → 手，前臂和手是同一组，法线合起来算、接触阴影只往下面投一次，手腕不出接缝；
  - 关节弯曲的外侧是一段圆弧，内侧是两条轮廓线相交挤出的褶，所以不会鼓出"球关节"。
- **衣服包着身体：** 裙子从腰上散开，盖住屁股和大腿，裙摆斜着绕过大腿、在膝盖前几厘米；过了凳子前沿，布在两腿之间往下垂一点（不是一个方盒子）。
  泡泡袖是软布包住肩和上臂上端，袖口收一圈；白色小圆领的圆领片搭在胸口前，侧面看得见那道圆边；辫子扎在耳后低处，一小把，发梢分绺。
- **反应：** 鹤扬起头时她看呆了——眼睛睁大、眉毛抬起、嘴张开，身子不自觉往前探一点（手还搭在膝盖上，肩往前，手肘跟着弯），后面慢慢缓下来。
- **造型检查图**（`xm_sheet.js`）：固有色 | 剪影 | 简单打光。剪影缩小看也要读得出"背挺直坐着、专注看右上方"。
- **检查方法：** 渲染前用程序算出每帧头、手腕、手肘、肩、膝盖的位移，相邻帧超过阈值就报出来（第三稿最大 0.09 厘米/帧），同时检查手臂离拉直还差多少；渲染后把人物所在区域连续几十帧拼成逐帧图，看动作。
- 奶奶：这个镜头里没有出现，方向确定后按同样的画法重新设计。

## 第三版（已被第四版取代）：剪纸片式的纸人
> 设定：`renders/checkpoint1-v3/chars_lineup.jpg`；程序：`js/cut/xiaoman.js`、`js/cut/nainai.js`、`js/cut/rig.js`、`js/cut/render.js`。
> 第二版的造型太像团队之前的仓库（豆豆眼 + 腮红、粗墨线），改用民间剪纸、年画娃娃的造型语言重新设计。

- **小满：** 大圆脑袋（约占身高三分之一）、扇贝边齐刘海、头顶一撮呆毛、剪出来的大杏仁眼带一点高光和两笔睫毛、一个正圆的红脸蛋（年画娃娃的画法）、
  刻着发丝的马尾和红绒球；黄裙子镂空梅花透出浅一层的黄，白色扇贝领，腰上一根红缎带打结；红色小凉鞋。
- **奶奶：** 同样的大头比例，笑成一道弯的眼睛和眼角刻出来的两道笑纹、法令纹；圆框眼镜是一圈细纸环、镜腿连到耳朵；灰白头发刻着波纹往后梳成发髻，插一根红珠发簪；
  淡蓝衬衫镂空四瓣碎花透出白底、一排白扣子；深蓝宽裤、黑布鞋白鞋底；左腕绿玉镯；背有一点驼。
- **构造：** 髋 → 上身 → 头；肩 → 上臂 → 前臂 → 手；髋 → 大腿 → 小腿 → 脚。每片纸长度固定，只绕铆钉转；手的目标用两节 IK 算角度，够不着时胳膊伸直，**长度永远不变**。
  侧面镜头里肘只往下、往后弯；握签子时让拳心落在签子末端。
- **透视：** 离镜头远近不同的人按透视缩放（第 6 场床单后的奶奶按 0.84 米的深度缩小，床单挡住上半身，只露出裤腿和布鞋）。

## 画法
- **一笔画成：** 人物由几块柔软的形状组成（脸、头发、裙子、胳膊……）。先把所有形状描一遍双倍宽的墨线，再按前后顺序上色——后画的颜色盖住前面的内侧墨线，所以整个人只有一条连续的外轮廓，关节处没有拼接缝。袖子压在胸前、刘海压在额头这类动画师会画的内线单独补。
- **线条呼吸：** 线条每秒换 12 张（"一拍二"），沿线有轻微、低频的抖动，像手绘。
- **视角：** 正面、侧面、背面三个视角各自设计；镜头不会拍到没设计过的角度，所以不会出现 3D 那种"转到某个角度就变形"。
- **动作：** 姿势是一组语义控制量（前倾、耸肩、低头、歪头、转头）加上手脚的目标位置；四肢用两节骨 IK，肘、膝只往正确方向弯；**目标够不着时手停在最远处，胳膊永远不会被拉长**（动作测试里抓到过这个问题，已修好）。
- **光：** 固有色之上乘一层光照图；面向光源的一侧加亮边（马灯、床单的暖光），所以背影也能被光勾出来。

## 小满
- **9 岁，城里来的孙女，约 1.3 米。** 头比真实比例大，远景也读得出表情。
- **一眼认得出是小女孩：** 双马尾 + 红色小绒球、齐刘海、头顶一撮呆毛、圆脸大眼（外眼角一笔睫毛）、腮红；黄色白波点 A 字连衣裙配白色圆领、泡泡袖，背后腰上一个蝴蝶结；红色塑料凉鞋。
- **剪影：** 双马尾和呆毛让她从正面、侧面、背面、剪影里都认得出——第 6 场她背对镜头坐着看戏，只看后脑勺和蝴蝶结就知道是她。双马尾和呆毛也是跟随动作的来源（坐直时被甩起来，再弹回）。
- **表情：** 眼睛、眉毛、嘴三处一起动。眉毛画在刘海上面，被头发挡住也看得见。
- **动作性格：** 快、急、幅度大、坐不住。

## 奶奶
- **七十来岁，约 1.5 米，背有一点驼。** 手巧、有本事、有幽默感，不是可怜的孤独老人。
- **造型：** 灰白头发往后梳，低发髻插一根发簪（背影的标志）；圆框眼镜；眼睛常常笑成两道弯，眼尾笑纹、淡淡的法令纹和抬头纹；淡蓝底碎花的确良短袖衬衫、尖领、一排扣子；深蓝宽腿裤、黑布鞋白鞋底；左腕一只玉镯。
- **侧面：** 驼背让头往前探，看东西像在"打量"；操纵皮影时两手在胸前握签子，签子斜着往上伸到床单上的皮影。
- **动作性格：** 慢、稳、准；笑的时候整个身子都在笑。

## 两个人放在一起
- 颜色：小满暖（黄 + 红），奶奶冷（淡蓝 + 深蓝）。马灯下两人都被染暖，来电后被打回各自的颜色。
- 节奏：小满的动作"一下一下"，奶奶的动作"一口气"。

## 手
- 卡通四指手，每种手型是一条设计好的整体轮廓：放松、拳、握签子、指、捏、张开、挥手、微曲。奶奶的手大一号。
- 第 9 场的手影小狗需要专门的手型（食指中指无名指并拢做上颚、小指做下颚、拇指做耳朵），动作测试阶段做。
