# S18 八张候选集中快审：手、接触与相邻动作

**八张均未发现必须因多手、断腕或手穿脸而弃用的静态结构硬伤，可以作为同一 S18 试点的候选送入试接；不等于八张已获动画采用。** k05 的功能应按实际改为“笑后开始抬手”，k11 的情绪有偏窘/忧的风险。最终是否保留依三秒实际片，当前不建议追加生成。

已实看八张完整正确 alpha 合成、全部脸部及关键手臂原像素裁片，再看 s29_integration 的凳脚配准总览。未把透明区域隐藏红黄 RGB 当成可见杂边。每张尺寸与原件 SHA 见 [identity.json](identity.json)：k02 为 921×1707，其余为 922×1706。完整 requests 与 generation_manifest 已读取，本审不修改原件或仓库。

关键证据：[低位四张脸部](evidence/early_faces_native.png)、[低位/抬手四张臂手](evidence/early_arms_native.png)、[捂嘴四张脸手](evidence/late_faces_hands_native.png)。这些裁片保留原像素尺寸，只做正确 alpha 合成并加图名。

相邻动作的未决项：

- **k04→k05→调整后的 k06 v2**：k05 提供了此前试片缺少的离膝状态，但从 k05 的掌面向下悬手到 v2 的竖掌近口，仍须较大抬臂和转腕。不能因为多了一张就认定轨迹自然。k04 大口笑→k05 小口笑可以解释成笑后收口，若仍标“笑幅最大”则与实际矛盾。
- **母版 k07→k08↔k09**：静态接触均保住了；头肩移动与手同步的程度、衣纹改变和反复频率是否造成闪跳，只有正式序列能决定。
- **k09→k10→k11**：偷瞄方向有图像依据；k11 眉形是否被笑的上下文带成“忍笑”，或反而像忧虑，不能靠静图预先保证。

配准依据来自 s29_integration：[配准总览](evidence/registered_contact_by_s29.jpg)、[测量记录副本](registration_by_s29.json)。只用两凳脚作全局相似变换，第三凳角留出残差为约 1.50–4.30 px，没有用头或手把动作差异对齐掉。本审借该结果检查姿态，不把凳脚配准通过等同于角色局部形体稳定。

本轮是一次集中静图快审；没有生成或播放三秒序列，没有验证一拍三速度、真正的接触运动或最终灯光。推荐把这些候选连成同一条 S18 实际试片后集中决定保留/复用，避免逐张静图放行被误写成连续动画成立。
