## 声音对应（建议，未改音频/未听验）

F24=1.000秒开始较深内收，保持原布声起点；F36=1.500秒送边；F39=1.625秒压平；F65=2.708秒松持。布声应按这些真实接触点重新包络，不能为了旧3秒布声把压稳硬撑1.79秒。原皮革1.6秒=F38.4，最近整数F38，但本表压平触点F39比原声晚25ms；可由Opus按听验将皮革对到F39，或确认保留1.6秒仍贴合。松持只在有听觉需要时保留轻尾音，不添反复摩擦。机器可读见 `reports/exposure_and_cues.json`。

## 固定点与真实风险

target A=(370,994)、B=(367,1340)，独立H=(163,1264)；所有候选用同一母图、同一90×125固定窗测量，A/B完整小数直接存入flip，H不参与配准。D/T/P/R/B 的H残差约0.15/1.26/0.62/0.79/1.41px，均小于3px。**H不是单独通行证**：B脚NCC随链下降到0.561，H到0.627，凳纹/线条有重画。协调已实看原生alpha同凳结构；P对母图脚轮廓约1–3px差异；没有先贴母凳救数字。T实际额外内收约45/20px大于请求；裤腿内折线重画，R局部脸/镜圈有小幅上移形变。三红珠、双镜圈、唯一左镯、蓝印花包、可读手指与凳鞋身份经实际检查。以上只支持条件接景，不能替代原速成片判断。

## 标准派生与核验

脚本为 d0fa610fe8b4eccbe93cef016a9e88cc55fa01e8 的原样快照，仅在本目录运行 `prep_flip.py → card_maps.py → card_soft.py`。RGBA按标准 `alpha=round(clip((alpha−6)/(247−6),0,1)×255)`，即≤6清零、≥247拉满；RGB逐像素保留。无裁切、无其他修图。`inputs/` 只是指向本机原件的软链接，不作为仓库依赖。
