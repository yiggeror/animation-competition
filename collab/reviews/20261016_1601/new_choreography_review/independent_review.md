# 《来电》S16 / S17 / S21 / S23 / S27 独立动作与参数审查

审查时间：2026-10-16 15:06 UTC。固定版本：`e0c65c3ed0a7aebdcdf39a744c0833c6da617d62`，涵盖 `0ed79bb`（14:52床单动作）及 `e0c65c3`（14:55来电）。本报告未修改共享仓库、未发布GitHub意见。检查结束时远端跟踪引用仍为该提交，仓库工作树干净。

## 结论先行

须先修正三个故事动作的实际接触关系，再验收视频：

1. **S23 没有咬住鹤嘴。** “咬住后僵住”的 1.6–2.4 秒，龟嘴与鹤喙轮廓相距约 **100 mm**，整颗龟头与喙也相隔 **38 mm**。之后甩动并未锁定咬点，反复分离和穿插。
2. **S17 第一下不是啄空，而是先撞壳、再啄入缩回的头。** 第二下在 8.5 秒确实碰壳。因此当前第一下破坏了“第一次躲过 → 第二次撞壳才晕”的因果。
3. **S16 啄水离真实水线仍约 98 mm。** 比较的是同一幕面、同一投影 x 处的喙尖与水纹顶线，已计入两者不同的离幕距离。

S21 的忽大忽小/忽清忽虚有实际几何支撑，检查帧内没有发现越幕/越画幅。S27 的日光灯确实大幅冲淡影子，曝光会削弱亮起的冲击；后者属于需实际WebGL视频与邻镜判断的视觉风险，不能仅凭本次参数采样判为失败。

## 证据范围与方法

- 从共享clone执行 `git archive` 到本目录 `source/`，没有 checkout、改动或提交共享clone。
- `probe.cjs` 直接载入归档的 shot、`makeCrane`、`makeTurtle`、`solve`、`pointOn`、纹理绘制方法。对未导出的 `sheet` / `exp`，只在内存导入文本中补导出；原文件保持不变。
- S17 / S23 以 **240 Hz** 采样；部件点通过原正向运动学转换为世界 x/z。喙轮廓取原多边形，壳/头取原 `spline` 生成轮廓。距离单位为毫米。
- 负的轮廓距离表示有轮廓采样点已落入另一片内部，其绝对值不是完整“穿透深度”。另外用原部件纹理 alpha 在 **2 px/mm、alpha > 127** 下复核交叠，包含原描边和镂空。
- `evidence/S*.png` 和拼图为**实际FK、原纹理的无光照正交诊断**。它们不含最终相机透视、幕布光照、半影、雾或泛光，不能冒充成片截图。S17/S23两只皮影距离均为0.004m，投到同一幕面时是共同的1.005747倍仿射投影；不接触和穿插关系不会被这一步消除。
- S16的水/喙比较明确在投影幕面进行。S21另以实际 `camera()` 投影检查1920×1080画幅。
- S27用原 `sheetImage()` 取得透光mask，复用着色器核心辐射、曝光、ACES和gamma公式，作定点对照；省略织纹/褶皱/暗角/雾/泛光/颗粒，不是完整WebGL渲染。
- 本次没有浏览器操作、没有新视频，也没有安装软件；使用环境已安装的 `@napi-rs/canvas`，仅生成项目源码诊断图，不生成入片图片素材。

## P1：S23 咬点未接触，也没有保持约束

相关源码：`js/lamp/shots/s23.js:9–19`，`js/lamp/turtle.js:83–94`。

1.6–2.4秒参数固定，实际世界坐标：

- 龟嘴线前端（head局部 `[57,-4] × 1.3`）：`[1.525577, 0.556994] m`
- 鹤喙尖（head局部 `[136,1] × 1.35`）：`[1.643412, 0.489801] m`
- 龟嘴至喙尖：135.65 mm
- 龟嘴至整个喙填充轮廓的最短距离：100.15 mm
- 龟头整体至喙轮廓的最短距离：38.41 mm；原纹理头/喙alpha交叠面积0

图 `evidence/S23_1.600.png` 显示喙垂到龟颈附近，龟嘴在左上方。2.4–4.8秒甩动期间，嘴至喙的最短距离仍在 **24.93–151.78 mm** 波动；龟头整体与鹤头/喙反复穿插。3.4833秒，两个原头部纹理（鹤头纹理含喙）的不透明alpha交叠约 **1862.5 mm²**，这是穿插，不能用来证明咬点成立。

原因：两只根点、根角和颈角各自受 `shake` 驱动；没有把龟嘴绑定到喙上的某个真实点。`turtlePose` 的 `bite` 只给整颗头加角度，不执行接触约束，也无独立下颌。

最小修复：先选真实龟嘴/鹤喙接触点，解出1.6秒咬合姿态；僵住与甩头时保持该点的世界/幕面位置约束，以咬点推导龟身摆动。不要通过改影子透明度掩盖空隙。是否新增下颌可另行决定，首先必须让现有嘴与喙接触。

## P1：S17 第一啄穿过壳与缩头，反转了叙事

相关源码：`js/lamp/shots/s17.js:21–38`，`js/lamp/turtle.js:90–93`。

240Hz轮廓扫描得到：

- 第一啄下落中，约 **5.725–5.779s** 已穿到壳前缘；5.75s原纹理alpha交叠约 **64.5 mm²**。
- 缩头发生在5.75–5.85s，但头是折到壳前下方，仍露在喙的落点里。
- 约 **5.808–6.096s** 喙与龟头穿插；5.825s有轮廓采样点落入龟头内部约23.92mm，原纹理alpha交叠约 **85.0 mm²**。5.85s诊断图清楚显示喙尖进入龟头。
- 第一啄抬回过程中，约 **6.121–6.217s** 又经过壳前缘。
- 第二啄约 **8.454–8.563s** 触壳；8.5s喙轮廓有点进入壳内约8.88mm，原纹理alpha交叠约 **41.0 mm²**。因此第二下“撞壳”有真实几何接触，不应误报成未碰到。

这不是仅凭注释或视觉猜测。两次接触时间段可在 `geometry_samples.json` 复查，纹理交叠见 `extra_samples.json`。

最小修复：分别给第一下设置“龟头原位置/缩走后空位”目标、给第二下设置壳的真实表面目标；第一条喙轨迹在下探和回收全程都应避开缩头与壳。保留第二下触壳后的回弹/晕，避免两下都成为碰撞。

## P1/P2：S16 低头有动作，但没有啄到水

相关源码：`js/lamp/shots/s16.js:11–14`；`js/lamp/choreo.js:5–6`；`js/lamp/s06_key.js` 中荷塘根点 `[1.30,0.34]`、距离0.003m；`js/lamp/scenery.js:14–17` 水顶线；`js/shadowplay.js:33–39` 灯到幕面的投影。

这里已把“同一幕面对应点”明确对齐：

1. 喙按皮影距离 **0.004m**，绕灯垂足 `(1.52,1.30)` 投影到床单。
2. 水纹按布景距离 **0.003m** 做同一物理投影。
3. 在投影喙尖的 **相同幕面 x=1.7296798m**，线性插值源码实际绘制的水顶折线（没有拿未投影的世界z直接比较）。

6.5–6.9秒最低姿态：

- 投影喙尖：`[1.729679824, 0.435037169] m`
- 同 x 的投影水顶线：`[1.729679824, 0.337241022] m`
- 垂直空隙：**97.796 mm**

6.0–7.6秒240Hz完整啄水段扫描，最小空隙仍为97.796mm。描边/毫米级半影无法补偿接近10cm的差距。建议用实际水线接触点约束颈部/头姿，顺带复核腿与身体位置；不要仅凭 `NECK_DOWN` 名称认定啄水完成。

梳毛段已可见回颈、喙与翼身重叠；这次没有把贴身梳羽的风格化交叠单独升级为阻断。

## S21：所承诺的几何变化确实存在

相关源码：`js/lamp/shots/s21.js:11–21`、`js/shadowplay.js:33–39,73–79`。

- 24fps采样，离幕最远约 **0.2392m @0.7083s**；投影放大约 **1.5191倍**，贴幕时为1.00575倍。
- 最远时由公式得到火芯半影半宽约 **5.71mm**，灯罩半影半宽约 **28.55mm**；实际blur传入时还乘0.55等系数。距离确实同时影响大小与虚实。
- 原纹理alpha边界采样经幕面和真实CAM_B投影后，没有发现越出2.10×1.82m床单，也没有越出1920×1080画幅。末尾最低轮廓约z=0.2627m，画面y约1044px，离底较近但尚在内。
- 未检验最终WebGL下花纹/签子与角色叠影是否足够易读，仍需视频；当前没有足够证据把它列为必须修的动作失败。

## S27：曝光部分抵消冲击，作为视觉风险保留

相关源码：`js/lamp/shots/s27.js:9–11,25–27`；`js/lamp/s06_key.js:209–231`；`js/lamp/shaders.js:294–305,332–335,489–504`。

已证明的参数行为：

- 首亮就把曝光倍率从常态1降到 **0.510204**，并非先保持曝光再缓慢收回。
- 0.12–0.22s和0.30–0.52s的“灭”阶段 `fluor=0.05`，曝光回到0.954198。
- 0.52s白灯暂为1.15，曝光仍0.510204；1.32s起曝光固定 **0.384615**。
- 白灯项加在幕布辐射上，未把影子mask擦除；该机制确实降低局部对比度。

定点辐射诊断（固定S27开场姿态，0–2s姿态本来也未变；数值为0–1显示亮度代理Y′，不是完整成片像素）：

| 点 | 仅马灯对比度 | 首亮t=0 | 稳定t=2 |
| --- | ---: | ---: | ---: |
| 鹤黑头相对同位置无影布面 | 95.0% | 9.1% | 11.8% |
| 鹤深色脖子 | 99.6% | 8.2% | 10.7% |
| 龟壳选定色块 | 36.7% | 2.9% | 3.8% |

这说明“冲淡”已经发生，不能判定该功能失效。曝光回收会让浓黑影子的显示对比从首亮约9%回升至稳定约12%；是否达到艺术上“几乎看不见”，须用最终帧与前镜S26对照。局部马灯芯Y′由0.959降至0.947/0.925，只能说明该局部变暗，**不能据此推出整幅不刺眼**。屋内其他表面会受白光照亮，完整雾/泛光/暗角也会改变观感。

最小验收：提交含0、0.125、0.25、0.333、0.542、1.333、2.5、4.5s的最终WebGL帧，以及S26尾段→S27的24fps联剪。若实际冲击不足，优先调整白光与曝光恢复的相对时序/强度，不要另抹影子。S26当前EDL尚无实现模块，不能现在验收“上一场动作被来电打断”的姿态和节奏连续性。

## 可复现材料与运行

在本目录运行（已有 `@napi-rs/canvas`）：

```sh
node probe.cjs > probe.log 2>&1
node extra_probe.cjs > extra_probe.log 2>&1
node montage.cjs
```

- `geometry_samples.json`：固定提交、选择帧与S17/S23完整240Hz几何扫描
- `geometry_summary.json`：关键段最短/最长距离与时刻
- `extra_samples.json`：原纹理alpha交叠、水/喙同幕面采样、S21画幅边界、S27辐射采样
- `evidence/contact_diagnostics.png`：接触问题6格拼图
- `evidence/S23_1.600.png`：咬合静止段空隙
- `evidence/S17_5.850.png`：第一次啄入缩头
- `evidence/S17_8.500.png`：第二次撞壳确实存在
- `evidence/S16_6.500.png`：低头姿态（图中不含水纹；水面结论以同幕面数值为准）
- `evidence/S27_actual_shadow_mask.png`：原代码生成的透光mask，非最终照明帧

所有被审查JS均通过 `node --check`；项目没有现成单元测试脚本。未运行浏览器/WebGL、未合成新成片、未替代真实视觉验收。后续只需围绕真实嘴/喙/壳/水面接触点约束pose，再复核三段动作与S27最终镜头，不必重做整个光照系统。
