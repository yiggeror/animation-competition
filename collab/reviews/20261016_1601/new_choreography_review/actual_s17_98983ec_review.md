## 结论

**第一啄的P1在实际光照画面中仍然成立，尚不能验收“啄空”。** 缩头后没有形成可读空隙：喙尖在连续7帧落到龟头/头颈铆点位置；下落和抬起还分别擦过壳前缘。应先修这条轨迹，再交新版动态。

可保留的是乌龟进入、鹤发现它、两次下探的节拍框架，以及第二下真正触壳后抬起的动作。实际画面中的透光颜色、刻花轮廓和第二下接触都成立，不需要推倒光照系统。

v1还明确存在放腿/收腿各一次单帧突变。v2静帧条已有中间腿姿和更大的晃动姿态，显示修改方向有效，但**不能把这张静帧条当成v2全动态已经通过**。

## 实际可见P1：第一下没有啄空

此项根据实际帧复核，不只是重复之前的几何数字。

- **f137 / 5.7083s**：喙仍在壳上方，可见间隙。
- **f138 / 5.7500s**：喙尖已经贴入壳的左上前缘，龟头还未完成缩回。
- **f140–f146 / 5.8333–6.0833s**：头已折到壳前下方，但喙尖仍与龟头上缘及头颈铆点一带相交，没有落在空白幕面上。至少连续7个实际采样帧可见这一重叠。
- **f148–f149 / 6.1667–6.2083s**：喙抬回时再次擦过壳前缘，然后离开。

原尺寸960×540下交叠面积不大，签影也经过附近，容易在快速观看时混为一团；但这正使“龟躲开了”的负空间不清楚。逐帧裁切可直接确认，并不能靠真实光照把它变成干净的空啄。无需在最终片中看清多少毫米才构成问题：故事要求第一下没有碰到，当前画面先碰壳、再碰头，第二下才晕的原因被削弱。

证据：

- `frames/f_0138.png`、`f_0140.png`、`f_0144.png`、`f_0148.png`：原始解码完整画面

建议仍是最小的接触目标调整：先确定伸头位置，再使缩头后的整个第一啄轨迹（含回收）绕开头与壳，在最低点留下可读的幕面空隙；不要另改影子透明度或涂掉碰撞。v2 diff只改晕和腿，没有改这一段，因此不能期待仅重新导出当前v2就修好第一啄。

## v1 晕与末尾回收：可见单帧换腿，v2尚待动态确认

### v1可确认的问题

1. **f208→f209 / 8.6667→8.7083s**：仍收起的腿直接换成垂下双腿，中间没有腿落下的姿态。放大条可见前一帧完整三角折腿，后一帧直接消失并合到竖腿。
2. **f316→f317 / 13.1667→13.2083s**：恢复时反向跳变，上一帧双腿直立，下一帧重新出现完整折腿。

这两处是提交的v1视频自身的真实不连续，不能作为最终动画通过。最新源码已经针对它们增加8.6–8.9s下放、12.6–13.2s收回插值，因此处理状态应写“v1确认、v2待动态复验”，而不是把旧视频问题当成最新源码仍然未改。

证据：`evidence/v1_leg_drop_every_frame.jpg` 与 `evidence/v1_leg_recovery_every_frame.jpg`。

### 晕与尾段的实际表现

v1在8.9–12.5s确实有连续的颈部起落/摆头，身体略摆；不是撞完完全不动。相比强烈“腿软、晕头转向”，当前更容易读成抬头后轻晃，表现力强弱属于动态/导演验收，不另立硬P1。

11.5s以后龟逐渐把头伸出，末尾仍有小幅试探性颤动；鹤也在收住。这一回收意图可辨识。除上述单帧收腿外，没有从实际帧发现必须另改的末尾结构问题。

证据：`evidence/dizzy_every_third_frame.jpg`，`evidence/end_recovery_every_frame.jpg`。前者是每3帧抽样辅助看姿态；完整帧全部保留。

## v2静帧条能证明什么

原图2400×852，4行×10列，共40格；图上标时约8.38–13.25s，间隔约0.125s。它是静帧抽样，不是完整24fps视频。

可确认：
- 8.62s仍折腿、8.75s出现下放中间姿、8.88s落到双腿，确实不再只有两个离散腿姿。
- 12.75 / 12.88 / 13.00 / 13.12s提供了收腿的逐步中间姿态。
- 9–11秒部分帧的躯干倾斜、头颈曲率和腿部弯曲比v1明显，增加了“晕”的表现材料。

不能确认：
- 这些采样帧之间每一帧是否连续、24fps播放的速度/重量感是否合适。
- 第一啄是否修好：静帧条根本没有5.5–6.3s；源码diff也未改该段。
- 0–8.38s整体和13.25–14s收尾的v2动态是否正常。
- 是否已把v2完整视频替换到剪辑链中。
