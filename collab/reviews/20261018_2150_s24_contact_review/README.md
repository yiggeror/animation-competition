## 根因与相机

本镜 `scene_candidate/s24_drawn.js:80` 调 `sheet23(3.4+0.1*u,env)`，在60个样本实际扫过S23的3.400000–3.645833秒。`js/lamp/shots/s23.js:9–19` 分别给鹤和龟角度/root，没有接点约束。鹤12节脖子的角度累积变化，龟只做很小的独立root摆动，因此二者不可能自动保持咬合。

固定相机 `pos[3.15,1.62,1.12] / target[1.80,.62,.98] / hfov46` 没有镜内运动。S23正面CAM_B与S24后台机位相反，屏幕左右/透视变化是预期切机位；但同一床单面、同一角色dist=.004的两个真实接点若重合，任何这两个相机都会保持重合。本问题不是通过相机、雾、曝光或人物遮挡校正可以解决的。

## S23→S24 不能跳过的承接

固定EDL的S23长5秒。S23末采样t=119/24=4.958333秒，甩动包络已于4.8秒归零，shake=0。S24首帧却回拨t=3.4秒，shake=-0.287903；末帧变为+0.883732。它既未保持S23结束状态，也没有实际夹住。

S23自身末态亦无嘴部约束。源函数计算的龟嘴端到选定喙握点仍相差约12.77厘米；这是源码末态诊断，不冒称已经独立看过S23正式末帧。不能只修S24，再凭本镜首帧外观签跨镜连续。

## 明确的最小几何修法

详见 `OPUS_HANDOFF.md`。只需要既有 `solve/pointOn`，不需要新图、骨骼变形、相机改动、改材色或绘制新皮影。

选定“既有龟嘴线外端” M=[57×1.3,-4×1.3]mm；选定“既有喙刻缝末端” B=[126×1.35,1×1.35]mm，较喙几何尖端内缩13.5mm以形成插入式咬合。它们是依据现有形状给出的初始候选，必须由修后实际图确认视觉咬住，不能仅因锚点误差为零就批准。

对每一帧计算各自head上的世界(x,z)点：`world = root + [facing*q.x,q.y]/1000`，q来自 `pointOn(pup,solve(pup,pose),'head',localAnchor)`。令 `delta=Bworld-Mworld`，仅将龟的root平移delta，并用新root重建 `turtleRods`；鹤和龟的原骨角/rootAngle不动。

关键诊断值（世界x,z，单位米）：
- S24 F000 delta=(+0.0748023,-0.0856717)
- S24 F040 delta=(+0.0904354,-0.0751780)
- S24 F059 delta=(+0.1983216,+0.0321494)
- S23 F119原末态 delta=(+0.1158343,-0.0538421)

F059投影M≈(601,843)、B≈(446,846)，源锚点间约155.20px，和实际可见分离一致。F000/040的嘴锚点也各相隔约112px，因此不能以“喙与龟的某处交叠”签嘴部接触。以上root修正幅度并不小，虽然代码边界小，仍必须检查龟壳/签子有无出界或穿人。
