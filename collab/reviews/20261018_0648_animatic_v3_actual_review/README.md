## 新音轨实核

1. 在隔离目录从固定400530a的audio源码与EDL重建。交付PCM为1,948,000样本/声道、48kHz双声道；与独立重建该范围相比，3,896,000个声道值中292个不同，最大3 LSB，RMSE 0.0141 LSB。不是字节完全相等；细数在 `pcm_rebuild_comparison.json`。
2. 从两版实际MP4抽出的AAC完全相同，SHA256 `20c23781fdfb65fc67db7813f883444c6f5d10f192b700d2d528c87fd046ec3c`。用交付PCM独立重编码：1904包中1896包原字节相同，另外8包只差编码器字符串 `Lavc60.31.102`/`Lavc61.19.101`；统一该字符串后所有包字节相同。两者解码后的1,948,672样本/声道（含AAC尾部padding）逐样本完全相等，最大差0 LSB。priming skip=1024，两者一致；不把padding算作片长。
3. 最终成片AAC独立测得 −16.17 LUFS、−3.89 dBTP，满足既有≤−1.5 dBTP门槛。实际容器音轨40.583秒与整帧视频40.583333秒相差0.333毫秒，属于本次交付记录的时间刻度差，不称逐样本等长。
4. 新PCM与源码重建对应后，S07画外落席点1.06秒在全局31.143333秒（奶奶近景）；转步1.82/1.98秒在31.903333/32.063333秒（小满近景）；2.43秒首步在32.513333秒（已回全景）。这是实际音轨来源/时间对应核验，非试听“听起来顺”的结论。

复核方式：`python3 audio/build.py`；`ffmpeg -i <PCM> -c:a aac -b:a 256k -ar 48000 <reference.m4a>`；两源解码为pcm_s16le比较；对实际MP4跑 `loudnorm=I=-16:TP=-1.5:LRA=11:print_format=json`，读取input_i/input_tp。结果摘要见 `audio_summary.json`。
