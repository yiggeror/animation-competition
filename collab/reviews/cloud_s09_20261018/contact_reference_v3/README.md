局部 s 轴沿真实筒轴从尾盖指向灯口，n 轴朝近腕；单位为注册画布 px。左掌接触带 n=[−36,+12]、掌面 s=0。带内近手最前点约 s=6.07；扣除两侧合计 3.78px 人工读图预算，投影余量约 **2.29px**。该余量较小，且只在所画轮廓和有限掌带内成立。两张离掌图表示正间隙的施工目标，实际离掌画稿尚未生成或验收。

前提为 F026 拇指退 OFF，恢复与 F000 相容的握姿；实际退档图必须重新核对近手外轮廓。全局双臂、左掌五指和厚度、掌腕连接、完整前臂及三维接触仍需实际画稿检查。本提案不冻结整条手臂坐标，不构成触掌成片批准。作者与云端 6.1sol 已实看三张参考，未发现明确局部计算或因果错误；交 Astra 冻结后再画触掌段。
