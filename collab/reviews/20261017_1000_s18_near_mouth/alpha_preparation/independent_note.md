# 透明关键帧预处理独立短审

**支持采用这份最小补丁，限定于本次已经带有效 alpha 的 RGBA 输入。** 已实看 [原件左／重抠右对照](original_left_recut_right_stool.png)：右侧凳座板下缘出现明显红色碎边，凳腿内侧及腿边有黄色杂边，鞋底也出现红色外溢；左侧原件按原 alpha 合成没有这些可见污染。这与此前“原件正确 alpha 合成较干净”的结论并不矛盾，问题发生在接入预处理。

源码原因与实际图一致：冻结的 `cutout_reviewed.py:13` 先 `convert('RGB')` 丢弃原透明度，第 62–65 行再根据 RGB 分割重建 alpha，因而原先透明的隐藏颜色可能重新变为可见。已读取 [result.json](result.json)：root 的隔离实跑记录为原近透明→可见 10,116 像素、原可见→近透明 1,129 像素；这些数字是对已有结果的核阅，本审没有重新运行流程。

已审 [prep_flip_preserve_alpha.patch](prep_flip_preserve_alpha.patch)：有实际透明度的 RGBA 直接复制，随后继续现有 maps 生成；不透明输入保留原 cutout 分支。补丁没有为原始透明图另做颜色重抠，也没有把这项预处理修复混作姿势修正。

已读取 [corrected_result.json](corrected_result.json)：root 的隔离完整流程记录显示，固有色输出与 v2 原件逐字节一致（SHA256 `43ef437cc3ea30ae3e75e13b31defe5c12b0880f7f69a56f2d2d511325bf56e3`），固有色、法线、材质三图均为 922×1706，三者 alpha 均逐像素等于原件。结合补丁逻辑和原/重抠实际对照，证据足以支持这次最小修法。

范围：本次只读核图、代码和既有结果；未重跑、未改仓库、未重生。补丁尚不代表最终镜头打光或两人接景通过，也不改变两版人物未达到既定 k06 目标的独审结论。
