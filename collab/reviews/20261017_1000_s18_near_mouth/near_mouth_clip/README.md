这是供 Opus 互审的实际短片：**v2 → v1 → 既有母版 k07**，每态停3帧，24fps，共9帧、0.375秒。真实输入为**2张新生成图 + 1张既有母版**；没有新生 k04，没有完整笑出声到捂嘴的起手过程，也不是3秒动作完成。

- `manifest.json`：每帧索引、时间、原图SHA、配准PNG SHA、配准矩阵、合成平移矩阵、输出SHA、ffmpeg命令和ffprobe实测。

已验证两支MP4全部成功解码，帧数/24fps/时长相符；每态3张合成PNG字节完全相同，全部输入、帧、输出SHA通过复核。实看原输入、灰底三态及实际MP4解码关键帧，人物全身和凳子均完整；没有因源图透明像素下的灰色RGB产生灰底矩形闪烁。

仍保留：v1/v2没有精确服从低肘目标，头位偏移、领口/袖点重绘，以及既有母版与新图之间的描边/抠图观感差异。此片用于实际动作判断，**不构成正式采用或自然连续表演通过**。此阶段未声称实时观看视频后判定好看；最终观感由 Opus/用户判断。
