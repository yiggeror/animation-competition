# S29 / S30：准备吹灯与憋气头影候选 v2

本候选增加 script-v3 的「奶奶凑向马灯，鼓腮准备吹；电灯关掉后，鼓腮大头影在床单上停住」。马灯火焰始终亮着。S29 保留小满看手机后抬头的段落；S30 保留 TV +1.1 秒先关、+1.65 秒切门边绳、+4.4–7.9 秒人物拉绳、+6 秒日光灯灭和原手绳/脚动作。

## 新增画面

- S29 +10.0 秒切到奶奶头颈与原项目马灯近景；前 1.1 秒把同一原画卡片在世界中向灯移动约 5 cm，随后停止。没有改脸、拉大脸颊、做口型变形或吹灭火苗。
- S30 +7.9 秒后替换旧空绳尾插镜。新头颈 alpha 作为单部件不透光 actor 送进原 `renderShot → sheetImage`。使用原灯的 core / globe 两种半影，不是在屏幕上放黑轮廓贴纸。身体/肩袖不进入头影贴图；颈的下端在最终画框外。
- 原灯世界位置 `[1.52, 0.70, 1.30]` 不变。最终嘴唇锚点 `[1.43, 0.44, 1.23]`，嘴到火苗约 0.284 m。头平面距床单 0.44 m，放大率 `0.70 / (0.70 - 0.44) = 2.6923`。
- 后台相机朝负 y，原画左向映射到世界正 x；观众在床单前看，同一轮廓朝右。近景头卡仍保持该 x/z 平面，使用本项目卡片流程的一阶平面投影；不是改变头影方向来迁就画面。
- v1 的近距玻璃过亮和金属框遮鼻口已经退回。v2 改本镜后台机位，保留固定灯/头位；仅本镜派生透明玻璃卡和有界灯壳材质，原火苗仍使用 `makeLamp`。灯框和嘴之间留出明确空隙，灯罩可透见背景。

## 支承与画幅

floorplan 第 5 场起的马灯由麻绳吊在后台檩条上，沿用项目 `makeLamp` 的底座、提梁、挂线。局部相机固定，灯底与挂线都不随人物移动；挂线在画面上缘继续出框，支承点在近景之外，不新增无支承的移动灯。日光灯在 S29 保持亮，S30 新尾段为灯灭后的原床单场景。

独审通过范围是原图头颈；源右肩 x1023 / y约890 的截边不可入框。实际近景投影该截边最靠内为 x980.22，仍在 960 宽画幅外；开始靠近时为 x1021.39。头影只用另外派生的头/髻/珠/必要颈 alpha，未使用右肩截边。
