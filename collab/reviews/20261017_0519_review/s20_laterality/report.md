# S20 绿镯左右腕争议：按原图与新实片重新独立核验

**结论：不撤回“S20当前可见镜像形象的镯子未落在应有左腕”的具体结论；但必须把推理说清。** Opus所述“人物面南、东北机位位于人物左后方”在舞台几何上成立。与实际画面不符的是下一句“翻转后镯子在近侧手腕”：新实片的近侧大袖口始终连到裸腕，戴镯的持杆臂从另一侧小袖口伸出。此结论来自袖口—上臂—肘—腕的连续追踪，不靠手位高低或画面左右猜测。

旧审查的简写“水平翻转后解剖左右交换”不应单独充当证据，应补全为：**原图前景裸腕臂和后侧戴镯臂的遮挡关系，在二维镜像后仍保持；在当前朝左／左侧机位下，前景臂应读作左臂，却仍裸腕。** 镜像不是把摄影机绕到人物另一侧，也不会重新排序贴图内部两条手臂。

本审实际重新看了两张原图、处理后的g20卡图、新带声12fps视频，以及固定源码。只写 `/tmp/laidian-audit-s20-laterality/`；未修改仓库、重新生成、渲染或给Opus留言。

## 3. 对Opus机位解释的准确回应

**舞台方向这一半应认可。** 当前代码奶奶基点在约 `(1.13,1.10)`，前段机位 `(3.05,1.50)`；人物若朝南即负y，解剖左侧在东即正x，机位确实在其左后方。后段机位 `(2.55,1.70)` 相对笑时奶奶基点也在左后方。因此“该机位应主要看见左侧臂”是合理的。

**不能由这件事推出当前贴图戴镯臂已经变成近侧臂。** `s20.js` 的 `flipM=[-1,0,0,1,2*ox,0]` 只是二维水平镜像；随后整张人物卡作billboard投射。它不把原图的两臂拆开，不交换肩袖前后，不会让原后侧戴镯臂覆盖到大袖口前方。实际链条证明近侧大袖口仍连裸腕。

若坚持保留“原图这条戴镯臂仍是同一解剖左臂”的语义，也只能说明贴图内部前后关系与左后机位的表述不一致，不能据此宣称近臂有镯。若按当前可见的朝左形象读取近侧为左臂，则镯子在另一侧右腕。两种说法都不支持“当前画面已把镯子正确放在近侧左腕”的放行理由。

本次因此保留具体修复项，同时收窄论证：**不是所有图只要镜像都应报左右错；是这两张具有非对称绿镯、且臂链可辨的素材，在当前用法下确实需要对应调整。**

## 4. 最小处理，不动已成立的镜头设计
