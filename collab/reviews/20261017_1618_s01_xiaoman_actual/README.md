## 实片暴露的两个渲染检查点

1. **可复核的底部黑边**：F0–101有完整画宽的近黑底带，最大10行（F0/24），F48为8行、F72为6行、F96为2行，F102起消失。判断为每行≥99.9%像素RGB均<8；F000全帧图也肉眼核过。建议像S03顶部修复一样，先让S01相机覆盖范围在画布内，奶奶接入重渲时一并处理。当前s01.js起点y=BH/2+10且fit=1，几何上会露出画布下沿；这是与实帧相符的原因判断。
2. **人物细线有点断线感**：F000近腿内侧/膝弯、手臂内轮廓在4倍最近邻实际裁图中呈断续深点，源图相同线条连续。当前paintshot.js在人物强缩小drawImage的ax上未设imageSmoothingQuality，只有最终放大到成片的ctx设high；疑似缩小采样混叠，不把此推断写成已定位根因。建议你只做一张实际对照：角色合成缩小时启用high或一次高质量预缩，再看线是否更连续，不要为此重画角色/全片批渲。最少改动和是否采用由你的实帧对照定。
