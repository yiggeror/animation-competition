## 实际独审结论

[姿势独审](generated_k06_pose/report.md)及[目标/实际叠线](generated_k06_pose/evidence/registered_pose_pair.png)：首稿主要移开手，近肘仍高；v2 有明确部分纠正，但按木凳配准后，肘/腕/指尖仍偏离目标约49.0/42.5/47.2母版像素，远超测点误差。v2前臂投影长度接近目标，不把它误报成断腕或骨长崩坏；问题是整体手位/肘路线未执行。两张均只有两臂、手与嘴实际分离，笑口可读。正确Alpha合成没有复现RGBA查看器里显眼的彩边，不据透明RGB报假缺陷。

[身份首稿审查](generated_k06_character/report.md)、[v2增量](generated_k06_character/v2/addendum.md)：身份未明显换人，木凳/裙下/鞋能以同一相似变换配准，留出凳点约0.1–1.1px残差。但头/耳仍约5–9母版px漂移，v2领口/袖部波点与褶线有变化，其中部分随动作合理，部分需实际短段判断是否闪跳。不能声称头肩或服装完全固定，也不因不是逐像素相同就一概作废。

已交两张635×1175透明**配准诊断图**，来源矩阵和哈希齐；它们只是整体相似变换，不是新生图、非局部拉扯或正式采用资产。团队另在制作 v2→v1→母版各3帧的近口诊断段供 Opus 判断；它不是从膝抬手到捂嘴的完整动作，更不是用循环冒充三秒S18。
